# 오늘 쓴 <em>터미널 명령어</em>

오늘 수업에서 실제로 친 명령어들을 다시 정리했어요.

??? 1주차 본 수업 뒤 복습·자료 배포용. 실제 학생 터미널 기록에서 뽑았다.

---
<!-- class: g-green -->
## 오늘 쓴 명령어, <b>여섯 개</b>예요

^^^
| 명령어 | 하는 일 |
|---|---|
| `ssh` | 서버에 접속한다 |
| `ls` | 지금 폴더에 뭐가 있는지 본다 |
| `cd` | 폴더에 들어가거나 나온다 |
| `cat` | 파일 내용을 화면에 그대로 본다 |
| `nano` | 파일을 열어서 고친다 |
| `clear` | 지저분한 화면을 지운다 |

??? 하나씩 다음 장에서. "여러분 오늘 이 여섯 개를 전부 직접 썼어요"라고 먼저 말해준다.

---
## `ssh` 서버에 <b>접속해요</b>

```
ssh 내아이디@서버주소
```

^^^
- 비밀번호는 계정 카드에 있어요 — **쳐도 화면에 안 보이는 게 정상**
- 처음 한 번만 "이 서버를 신뢰합니까?" → `yes`
- 학원에서만 접속돼요

??? 비밀번호가 안 보여서 당황한 학생이 오늘 여럿 있었다 — "안 보이는 게 정상"을 다시 강조.

---
## `ls` 폴더 안을 <b>봐요</b>

```
ls        → project
ls -a     → .bashrc  .codex  project  ...
```

^^^
- `ls -a` 를 붙이면 **숨겨진 파일**까지 다 보여요
- 점(`.`)으로 시작하는 게 숨김 파일이에요

---
## `cd` 폴더를 <b>오가요</b>

```
cd project   → 안으로 들어가기
cd ..        → 한 단계 나오기
cd           → 어디서든 내 홈으로
```

^^^
> `cd`와 `..` 사이 **띄어쓰기 필수** — 오늘 제일 많이 걸린 함정이에요

??? 실제로 cd.. 를 친 학생이 여럿. 명령어와 대상은 항상 한 칸 띄운다는 규칙으로 일반화해준다.

---
## `cat` 파일을 <b>봐요</b> · `nano` 파일을 <b>고쳐요</b>

```
cat AGENTS.md    → 내용이 주르륵 (보기만)
nano AGENTS.md   → 편집 화면으로 (고치기)
```

^^^
- nano 저장: `Ctrl+O` → Enter · 나가기: `Ctrl+X`
- 화면 맨 아래에 단축키가 항상 떠 있어요

## 전부 <b>정상적인 과정</b>이에요

??? 실수한 학생을 웃음거리로 만들지 않는 것이 포인트 — "이거 오늘 세 명이 했어요, 아주 정상이에요" 톤.

---
<!-- class: g-orange -->
## 오늘의 실수 ① <b>띄어쓰기와 오타</b>

^^^
| 친 것 | 결과 | 바른 것 |
|---|---|---|
| `cd..` | 안 됨 | `cd ..` (한 칸 띄우기) |
| `cd projsct` | No such file | `cd project` |
| `is` | command not found | `ls` (소문자 L + s) |

^^^
> 꿀팁: `cd pro` 까지 치고 **Tab 키** — 나머지를 자동 완성해줘요. 오타 원천 차단.

??? Tab 완성은 오늘 못 가르친 것 중 제일 아까운 것. 다음 주 첫 실습에서 전원 시켜본다.

---
## 오늘의 실수 ② <b>이름은 한 글자도 달라지면 안 돼요</b>

^^^
| 친 것 | 결과 | 왜 |
|---|---|---|
| `cat Agent.md` | 안 됨 | 대문자·소문자는 **다른 글자** — `AGENTS.md` |
| `SERVER-RULES.md` | command not found | 파일 이름만 치면 **명령어인 줄 알아요** → `cat SERVER-RULES.md` |

---
## 오늘의 실수 ③ <b>Permission denied</b>

```
nano AGENTS.md → 저장하려니 Permission denied
```

^^^
- 이건 실수가 아니라 **일부러 막아둔 거예요**
- AGENTS.md는 수업용 지시서 — 읽기만 되고 못 고쳐요
- 여러분 잘못이 아니에요
