# 검증 원칙 — 문서보다 실물을 믿는다

> 이 프로젝트에서 반복해서 얻은 교훈을 규칙으로 남깁니다.
> "문서에 그렇게 쓰여 있다"는 근거가 되지 못한 사례가 여러 번 나왔습니다.

---

## 원칙

**1. 실행되는 것으로 확인한다.** 블로그·문서·검색 결과는 출발점이지 결론이 아닙니다.
설치된 바이너리, 실제 응답, 실제 화면이 기준입니다.

**2. 통과를 믿기 전에 실패를 확인한다.** 검사기가 "통과"라고 하면,
**일부러 틀린 입력을 넣어 실패가 잡히는지** 먼저 봅니다. 잡지 못하는 검사기의 통과는 무의미합니다.

**3. 안 되는 것도 결과다.** 확인하지 못한 것은 "확인 못 함"이라고 적습니다.
추정을 사실처럼 적으면 나중에 그 위에 쌓은 판단이 전부 흔들립니다.

**4. 근거를 결정 기록에 남긴다.** 무엇을 어떻게 확인했는지까지 적습니다.
6개월 뒤 같은 질문이 다시 나올 때 재조사 비용을 없앱니다.

---

## 실제 사례

### 스킬 경로 — 문서 3곳이 서로 달랐다

**상황**: Codex 스킬을 어디 둬야 하는지 자료마다 달랐습니다 —
`~/.claude/skills`(Claude용, 애초에 무관), `~/.agents/skills`(공식 문서), `~/.codex/skills`(블로그).

**확인 방법**: 설치된 네이티브 바이너리의 문자열을 직접 셌습니다.

```bash
B=$(find /usr/lib/node_modules/@openai/codex -name codex -type f -perm -u+x | head -1)
strings "$B" | grep -oE '\$CODEX_HOME/skills|\.codex/skills|agents/skills' | sort | uniq -c
```

**결과**: `$CODEX_HOME/skills` 12회, `.codex/skills` 3회, `agents/skills` **0회**.
공식 문서가 안내한 경로가 설치된 버전(0.147.0)에는 존재하지 않았습니다.

**교훈**: 버전이 다르면 문서가 틀립니다. **내가 설치한 것**을 봐야 합니다.

### 설정 검증기 — "통과"가 거짓이었다

**상황**: `codex --strict-config`로 설정을 검증하고 통과했다고 판단했습니다.

**문제**: 검사 스크립트가 `"unknown field"`를 찾고 있었는데 실제 메시지는
`"unknown configuration field"`였습니다. **일부러 넣은 엉터리 키도 "통과"로 나왔습니다.**

**교훈**: 검사기를 만들면 **대조군(반드시 실패해야 하는 입력)**을 먼저 통과시켜 봅니다.

### 모션 — 코드에 있는 것과 재생되는 것은 다르다

**상황**: 슬라이드 모션이 코드에 다 있는데 "안 보인다"는 보고를 받았습니다.

**확인 방법**: 헤드리스 브라우저를 설치해 실제로 재생 중인 애니메이션 수를 셌습니다.

```bash
python3 scripts/verify-motion.py decks/w01-orientation.html
```

**결과**: 코드는 정상이었고 원인은 두 가지였습니다 — 보는 기기의 OS 모션 저감 설정,
그리고 이전 버전 파일을 열고 있었던 것. **정적 검사(코드에 있는가)와 실기 검사(재생되는가)는
다른 것**이라 스펙에 8-1·8-2로 분리했습니다.

### 정리 스크립트 — 되돌릴 수 없는 것을 지웠다

**상황**: 홈 초기화 스크립트가 `.git`과 자격증명을 함께 지워 push가 막혔습니다.

**교훈**: 삭제·초기화 스크립트는 **제외 목록을 먼저 쓰고** 시험 계정에서 왕복을 확인합니다.
"지운 뒤 복구되는가"까지 봐야 검증입니다.

## 체크리스트

새 도구·설정·외부 서비스를 도입할 때:

- [ ] 공식 문서를 읽되, **설치된 버전에서** 동작을 확인했는가
- [ ] 검사기를 만들었다면, **실패해야 하는 입력이 실패하는지** 봤는가
- [ ] 확인하지 못한 항목을 문서에 "미검증"으로 남겼는가
- [ ] 결정 기록에 **무엇을 어떻게 확인했는지** 적었는가
- [ ] 파괴적 동작이면, 제외 목록과 복구 경로를 먼저 만들었는가
