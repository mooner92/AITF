
## 3. 시간표 (120분)

노트 합계 **98분 + 휴식 10분 = 108분**. 12분 여유가 접속 지연 흡수분입니다.

| 시각 | 블록 | 분 | 비고 |
|---|---|---|---|
| 0:00 | 강사 소개 · 12주 안내 · 약속 3줄 | 20 | 슬라이드 1~9장 |
| 0:20 | **접속 5단계** | 25 | **최대 변수** — 4절 |
| 0:45 | tmux 3키 · 세션 지속 시연 | 12 | |
| 0:57 | 휴식 | 10 | |
| 1:07 | **프로필 카드 만들기** | 15 | **줄이지 않습니다** |
| 1:22 | 고쳐 쓰기 반복 | 8 | |
| 1:30 | 할루시네이션 시연 | 5 | 강사 이름으로 |
| 1:35 | 사용량 그래프 | 5 | 순위 없이, 각자 것만 |
| 1:40 | 위키 예고 · 다음 주 안내 | 3 | |
| 1:43 | 여유 | 17 | 지연 흡수 |

**밀렸을 때 자르는 순서**: ① 고쳐 쓰기 8분 → ② 사용량 그래프 5분 → ③ 약속 3줄.
**프로필 카드와 할루시네이션 시연은 자르지 않습니다.**

## 4. 접속 5단계 (25분 — 오늘의 고비)

학생 화면에 이 순서대로 뜹니다. **한 단계씩 다 같이** 갑니다.

1. 브라우저에서 `aitf.excusa.uk` 열기
2. 인증 1회 (학원 IP 등록 전이라 필요 — 등록되면 이 단계가 사라집니다)
3. 계정 카드의 아이디·비밀번호 입력
4. 검은 화면(터미널)이 뜨면 성공
5. `ls` 를 쳐서 `project` 폴더가 보이면 완료

**운영 요령**

- 3~4명씩 확인하며 진행. 다 된 학생은 손을 내리게 해서 남은 학생을 파악합니다
- **20분이 지나면** 안 된 학생을 옆자리와 붙여 **화면 공유**로 진도를 뺍니다
  (혼자 못 따라오는 것보다 같이 보는 게 낫습니다)
- 계정 문제는 **쉬는 시간에** 처리합니다. 수업을 세우지 않습니다

## 5. 프로필 카드 실습 (15분 — 오늘의 정점)

학생이 칠 문장(슬라이드에 있습니다):

```
내 롤 닉네임은 OOO이야.
op.gg에서 내 전적을 찾아서
터미널에 보여줄 프로필 카드를 만들어줘.
```

- 게임을 안 하는 학생은 **좋아하는 것 아무거나** — 아이돌·유튜버·팀·캐릭터
- **검색이 안 걸리면** "웹에서 찾아봐줘"를 덧붙이게 합니다
- 빨리 끝낸 학생: "색을 넣어달라고 해봐" / "테두리를 바꿔봐"

> 이 장의 목적은 **"AI가 인터넷에서 나를 찾아온다"**는 경험입니다.
> 카드가 예쁘게 나오는 것보다, 자기 정보가 화면에 뜨는 순간이 중요합니다.

**바로 이어서 할루시네이션 시연** — 같은 AI에게 검색 없이 강사 이름을 묻습니다.
"찾아보면 맞히고, 안 찾으면 지어낸다"는 대비가 오늘의 핵심 교훈입니다.

## 7. 사고 대응

### 7-1. 서버 서비스가 빨강

```bash
systemctl status nginx gitea          # 죽었으면
sudo systemctl restart nginx          # 또는 gitea
sudo tail -30 /var/log/nginx/error.log
```

### 7-2. 학원에서 사이트가 안 열림

1. 폰 LTE로 접속 → **되면 학원 네트워크 문제**, 안 되면 서버 문제
2. 학원 문제면: 와이파이 재접속 → 다른 브라우저 → 방화벽 차단 의심
3. **최후 수단**: 강사 폰 핫스팟으로 노트북 연결 후 프로젝터로 진행,
   학생은 짝 화면 공유. 수업은 계속됩니다

### 7-3. 학생 하나만 로그인 실패

- 계정 카드 오타 확인 (특히 `l`/`1`, `O`/`0`)
- 그래도 안 되면 **예비 계정으로 진행**시키고 쉬는 시간에 처리:
  ```bash
  sudo passwd ⟪계정⟫          # 비밀번호 재설정
  ```

### 7-4. AI가 응답하지 않음

```bash
# 키가 주입돼 있는지 (학생 홈의 .bashrc 를 직접 확인 — 로그인하지 않으므로 깔끔합니다)
sudo grep -c OPENAI_API_KEY /home/⟪계정⟫/.bashrc
```

- 키가 비어 있으면 그 계정만 미주입 → 재주입
- 전원이 안 되면 **API 상한 소진** 가능성 → 대시보드 확인.
  이 경우 강사 화면으로 시연 전환하고 실습은 다음 주로

### 7-5. 터미널이 멈춘 것 같음

학생에게 **`Ctrl-C`** 를 누르게 합니다(중단). 그래도 안 되면 탭을 닫고 다시 접속 —
tmux라 하던 게 그대로 있습니다. **이게 오히려 좋은 시연 기회**입니다.
