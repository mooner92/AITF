## 5. 프로필 카드 실습 (30분 — 오늘의 정점)

학생이 칠 문장(슬라이드에 있습니다):

```
내 프로필 카드를 HTML로 만들어줘.
내가 좋아하는 OOO 정보를 웹에서 찾아서 넣어줘.
```

- 게임을 안 하는 학생은 **좋아하는 것 아무거나** — 아이돌·유튜버·팀·캐릭터

**파일로 만드는 법** (ChatGPT는 코드를 화면에 보여주기만 합니다):

1. 코드 전체 복사
2. 메모장 열기
3. 붙여넣고 `me.html` 로 저장 (파일 형식 "모든 파일" — 흔한 실수 지점)
4. 더블클릭해서 열기

**"다운로드할 수 있게 해줘"를 넣으면 ChatGPT가 코드 창(캔버스)을 열고 다운로드
버튼을 줍니다** — 메모장 복사·붙여넣기보다 실패 지점이 적어 이 경로를 기본으로
합니다. 캔버스가 안 뜨는 학생은 "코드 창으로 보여줘"를 덧붙이게 하고, 그래도
안 되면 기존 방식(전체 복사 → 메모장 → `me.html` 저장)으로 갑니다.

**그다음 "색을 바꿔줘" 같은 수정을 2~3번 반복시킵니다.** 매번 전체 코드를 다시 받아
다운로드·새로고침을 겪게 하는 게 핵심입니다 — 이 번거로움이 다음 주(Codex)
필요성의 재료입니다. **강사가 먼저 "번거롭죠"라고 말하지 않습니다.** 학생이
스스로 그 말을 할 때까지 기다립니다.

> 이 장의 목적은 **"AI가 인터넷에서 나를 찾아온다"** + **"직접 배포·수정하는 게 번거롭다"**
> 는 두 경험입니다. 카드가 예쁘게 나오는 것보다 이 두 가지가 중요합니다.

**바로 이어서 검증 시연** — 같은 계정에 강사 이름을 묻습니다. 최신 모델은 자동
검색·되묻기를 해서 "완전한 헛소리"는 드뭅니다 — 대신 **동명이인을 자신 있게
설명**하거나 근거 없는 세부를 섞는 경우가 많고, 어느 쪽이 나와도 교훈은 같습니다:
**그럴듯함 ≠ 맞음.** 전날 실측이 필수이고, 결과별 받는 말이 대본에 있습니다.

**그 사이 — 완성한 카드를 Gitea에 올립니다:**

1. 처음 나눠드린 계정 카드로 Gitea 접속·로그인 (ChatGPT 계정과 다름 — 헷갈리지 않게 짚어줄 것)
2. `project` 저장소 열기 → **Upload file** → `me.html` 드래그 → **Commit Changes**

**마지막 — 핸드오프 의식** (오늘 처음 도입, 12주 내내 반복):

```
오늘 내가 뭘 만들었는지,
다음에 이어서 할 수 있게 정리해줘.
```

결과를 같이 읽고, 다음 주에도 매주 수업 끝에 이걸 한다고 알려줍니다.

## 7. 사고 대응

### 7-1. `chatgpt.com` 이 학원에서 안 열림

1. 폰 LTE로 접속 → **되면 학원 네트워크 문제**, 안 되면 OpenAI 쪽 문제
2. 학원 문제면: 와이파이 재접속 → 다른 브라우저 → 방화벽 차단 의심
   (어제 현장에서 접속 확인됐으므로, 새로 막혔다면 학원 쪽 변경을 의심)
3. **최후 수단**: 강사 폰 핫스팟으로 진행, 학생은 짝 화면 공유

### 7-2. 학생 하나만 가입 실패

- gmail 아이디·비밀번호 오타 확인
- 전화번호 인증에서 막히면 쉬는 시간에 개별 처리
- 그래도 안 되면 **부모님 계정으로 임시 진행**시키고, 다음 주까지 본인 계정 준비 안내

### 7-3. ChatGPT가 이상한 응답만 함 / 안 됨

- 새 대화(New chat)로 다시 시작
- 그래도 안 되면 강사 화면으로 시연 전환하고, 학생은 관찰만 하다가 복구되면 이어서

### 7-4. 다운로드가 안 되거나 파일이 깨짐

- 캔버스 다운로드 버튼이 안 보이면 "코드 창(캔버스)으로 다시 보여줘" 요청
- 그래도 안 되면 대체 경로: 코드 전체 복사 → 메모장 → **파일 형식을 "모든 파일"로**
  선택하고 `me.html` 저장 (텍스트 문서로 저장돼 `me.html.txt` 가 되는 게 흔한 실수)
- 그래도 안 열리면 코드를 다시 복사해 처음부터

### 7-6. Gitea 업로드가 안 됨

- 로그인 실패 → **ChatGPT 계정이 아니라 처음 나눠드린 계정 카드**인지 확인
- 그래도 안 되면 강사가 화면 공유로 대신 받아 업로드, 쉬는 시간 없이 진행

### 7-5. 프로젝터·네트워크 등 일반 사고

- 프로젝터 안 나옴 → 케이블 재연결, 노트북 디스플레이 모드(윈도우 키+P) 확인
- 인터넷 느림 → 다른 반·사무실 기기 사용량 확인, 쉬는 시간에 재확인
