## 1. 왜 터미널이 아직 없나

터미널은 Cloudflare 터널의 `sshopc.excusa.uk` 로 열기로 설계돼 있고,
설정 파일에 **주석 처리된 채** 대기 중입니다.

```yaml
# - hostname: sshopc.excusa.uk
#   service: ssh://localhost:22
```

주석을 푸는 조건이 파일에 그대로 적혀 있습니다 — **Cloudflare Access 정책을 먼저 만들 것.**
정책 없이 열면 서버 SSH가 인터넷에 그대로 노출됩니다. 그래서 지금 열려 있지 않은 게 맞습니다.

**정책은 둘 중 하나 이상:**

| 방식 | 효과 | 필요한 것 |
|---|---|---|
| **Bypass — 학원 고정 IP** | 수업 중 로그인 화면이 **아예 안 뜸** | **오늘 알아 올 것** |
| **Allow — 이메일 OTP** | 집에서도 접속 가능. 대신 매번 메일 인증 | 학생 gmail |

> **개강일 접속 5단계가 25분에서 15분으로 줄어드는 게 Bypass 하나에 달려 있습니다.**
> 오늘의 최우선 임무가 이것입니다.

## 2. 도착 즉시 (10분) — 오늘의 최우선

### 2-1. 학원 공인 IP 확보

**학생들이 실제로 쓸 와이파이**에 노트북을 붙인 뒤, 브라우저 주소창에:

```
ifconfig.me
```

화면에 뜨는 숫자를 **그대로 적어 옵니다.**

- [ ] IP: `___.___.___.___`

**원장님께 반드시 확인할 것 두 가지:**

- [ ] 이 IP가 **고정인지 유동인지** — 유동이면 Bypass가 며칠 뒤 깨집니다
- [ ] **학생용 와이파이와 사무실 와이파이가 다른 망인지** — 다르면 학생 망 IP가 필요합니다

> 여기서 "유동"이라는 답이 나오면 Bypass는 포기하고 이메일 OTP로 갑니다.
> 그 경우 개강일 접속 시간을 **25분 그대로** 잡아야 합니다. 미리 아는 것과 당일 아는 것의 차이가 큽니다.

### 2-2. 학원 망에서 실제로 열리는지

브라우저 주소창에 하나씩:

- [ ] `aitf.excusa.uk` → 안내 페이지가 뜨는가
- [ ] `aitf.excusa.uk/git/` → Gitea 로그인 화면이 뜨는가
- [ ] 관제탑 → **진입 URL은 `/opt/scripts/hub-admin.txt` 에 있습니다. 출발 전 휴대폰 메모에 복사해 가세요**

> **하나라도 안 열리면 그게 오늘의 최대 수확입니다.** 학원 방화벽이 막는 것이므로
> 원장님께 "이 주소 열어달라"고 **오늘 요청해야** 개강일에 맞출 수 있습니다.
> 폰 LTE로 같은 주소를 열어보면 학원 문제인지 서버 문제인지 바로 갈립니다.

### 2-3. 학생 노트북으로도 한 번

강사 노트북만 되고 학생 노트북이 안 되는 경우가 있습니다.

- [ ] 학원 실습용 PC 한 대에서 `aitf.excusa.uk` 열기
- [ ] 브라우저가 뭔지 확인 (구버전 IE·엣지면 개강일에 문제)

|---|---|---|

> **API 키가 오늘 밤까지 안 들어오면 개강일 1주차의 정점(프로필 카드 15분)이 통째로 빕니다.**

## 6. 돌아와서 (같은 날 밤)

학원에서 받아온 IP를 손에 쥐고 순서대로:

1. **Cloudflare Zero Trust → Access → Applications** 에서 `sshopc.excusa.uk` 앱 생성
2. 정책: **Bypass — 학원 IP** (고정일 때) 또는 **Allow — 이메일 OTP**
3. DNS 에 `sshopc` 레코드 추가 (터널 CNAME)
4. `/etc/cloudflared/config.yml` 의 주석 두 줄 해제 → `sudo systemctl restart cloudflared`
5. **폰 LTE로 접속해서 로그인 화면이 뜨는지 확인** — 안 뜨고 바로 들어가지면 정책이 안 걸린 것이므로 **즉시 되돌립니다**
6. 그 다음에야 `sudo ./scripts/reset-test-account.sh test01` → `test-pipeline.sh` 로 1주차 실측

> 3~5번은 방화벽·노출과 직결됩니다. **제가 임의로 하지 않습니다.**
> 돌아오셔서 "터널 열어" 라고 말씀해 주시면 그때 함께 진행합니다.
