## 아직 실행하지 않은 것 (승인 대기)

**방화벽·포트 변경은 전부 여기 묶여 있고, 별도 승인 전까지 손대지 않습니다.**

| 항목 | 필요한 승인 |
|---|---|
| 학생 간 포트 격리 (iptables) | 운영자 |
| 학생 웹서비스 외부 개방 (10주차용 DNS·Access) | 운영자 + 학원 IP |
| SSH 22번 포트 (학원 IP 한정) | 운영자 |
| 회사 서버 로컬 모델 사용 | 회사 |

## 외부 의존 3건 — 이것만 오면 됩니다

| 필요한 것 | 무엇이 풀리나 | 걸리는 시간 |
|---|---|---|
| **학생 명단 + gmail** | 계정·저장소·포트·Slack 초대 일괄 생성 | 10분 (스크립트 완비) |
| **OpenAI API 키** | AI CLI 실동작, 비용 실측, 스킬 실호출 확인 | 반나절 (온보딩 문서 있음) |
| **학원 고정 IP** | 인증 없는 즉시 접속, SSH 범위 제한 | 10분 (규칙 1개) |

준비된 명령:

```bash
# 명단 받으면
./scripts/create-accounts.sh accounts.csv
./scripts/alloc-ports.sh accounts.csv --deploy
./scripts/deploy-skills.sh

# 키 받으면 → materials/instructor-codex-onboarding.md 6단계
# IP 받으면 → Cloudflare Access Bypass 규칙 1개
```
