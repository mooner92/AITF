## 왜 따로 만드나 — 070(OpenObserve)과의 관계

070은 **지표**(토큰·메모리·커밋 수의 시계열)를 담당한다. 그런데 수업을 운영하다 보면
지표가 아니라 **"내가 깔아둔 것들이 조용히 잘 돌고 있나 / 이번 주에 뭘 준비해야 하나 /
학생에게 나중에 줄 재료가 쌓이고 있나"**를 잊는다 — 자동 위키가 매주 쌓이고 있다는
사실 자체를 수업 중에 잊는 문제. 이건 대시보드 빌더로 만들 수 있는 화면이 아니라
**수업 운영 현황판**이므로 얇은 정적 페이지로 따로 둔다.

| | OpenObserve (070) | 관제탑 (이 문서) |
|---|---|---|
| 내용 | 토큰·리소스·진도 시계열 | 서비스 생존 · 자동화 최근 실행 · 주차별 준비 · 학생 적립 · 바로가기 |
| 갱신 | 수업 중 1분 | 5분 (cron) |
| 성격 | 분석 | 한눈 확인 + 진입점(런처) |

관제탑에서 Gitea 관리자·OpenObserve·위키 3종·작품관으로 **바로 이동**한다 —
"모든 걸 여기서 관리"의 실체는 각 도구의 관리 화면으로 가는 문이다. 각 도구의
관리 기능을 웹 버튼으로 재구현하지 않는다(070의 기존 결정 유지 — 실작업은 스크립트).

## 구성

```
scripts/hub-status.sh   ── cron(5분) → /srv/hub/status.json 생성
scripts/build-weeks.py  ── detailed-plan.md → /srv/hub/weeks.json (커리큘럼 변경 시 수동 실행)
web/hub/index.src.html  ── 페이지 소스 (편집 대상)
web/hub/build.py        ── Paperlogy 임베드 → index.html 생성
web/hub/index.html      ── 빌드 산출물. 배포 시 /srv/hub/index.html 로 복사
nginx location /hub/    ── 기존 서버 블록에 추가, 쿠키 게이트 (+ absolute_redirect off)
/opt/scripts/hub.env    ── DOMAIN=·COURSE_START= (서버에만 — 저장소에 실값 금지)
/opt/scripts/hub-notes.md ── 강사 수동 노트(외부 의존·결정 대기) → 페이지에 표시
/opt/scripts/roster.csv   ── 학생 명단(반·계정ID·이름·gmail). gmail 은 페이지로 안 나감
```

### 페이지 구역

1. **서비스** — nginx·Gitea·docker·터널·OpenObserve 생존 (초록/빨강 점)
2. **자동화** — 토큰 수집·스냅샷·자동 위키·리허설 로그의 마지막 실행 시각.
   오래됐으면 노랑 경고. **자동 위키는 미구축 상태가 그대로 보인다** — 개강 전
   필수(130)인데 아직이라는 사실이 매일 눈에 밟히게 하는 것이 의도다
3. **이번 주 / 주차별 준비** — `COURSE_START` 기준 주차 계산.
   내용은 **`curriculum/detailed-plan.md` 에서 자동 추출**한다 (`scripts/build-weeks.py`
   → `/srv/hub/weeks.json`). 주차마다 제목·★태그·만들기 목표·개발 역량·사용 기술·
   진행 단계·강사 준비 체크리스트가 모두 나온다.
   **손으로 옮겨 적지 않는다** — 커리큘럼이 바뀌면 관제탑이 조용히 낡기 때문이다.
   커리큘럼 수정 후 `python3 scripts/build-weeks.py` 한 번이면 반영된다.
4. **학생 적립 현황** — 계정별 커밋 수·작품 파일 수·마지막 활동. 12주차 포트폴리오
   재료가 실제로 쌓이는지 확인하는 자리
5. **바로가기** — Gitea 관리자(`/git/-/admin`)·위키 3종(120)·OpenObserve·작품관
6. **수동 노트** — hub-notes.md 원문 표시 (학원 IP·API 키·명단 등 외부 의존 메모)
7. **관리 명령** — 자주 쓰는 원라이너 복사 버튼 (실행은 터미널에서 — 웹에서 실행하지 않음)

## 보안

- `/hub/` 는 **쿠키 게이트**로 잠근다 (Basic 인증에서 교체 — 아래 결정 기록 참조).
  최초 1회 `/hub/enter?key=<KEY>` 로 들어오면 1년짜리 쿠키(`HttpOnly; Secure; SameSite=Lax`)를
  심고 이후 `/hub/` 가 열린다. 쿠키 없으면 403. 진입 URL은 `/opt/scripts/hub-admin.txt`(600)
- `/srv/hub` 는 root:nginx 750 — 학생 로컬 계정이 status.json 을 직접 못 읽는다
  (다른 학생의 활동 시각·커밋 수가 담기므로)
- status.json 에 **gmail·비밀번호·토큰은 절대 넣지 않는다.** 학생 **이름·반·계정 ID**는
  강사 전용 페이지에서 명단 관리에 필요하므로 포함하되, 유출 시 영향이 큰 연락처는
  서버(`roster.csv`, 600)에만 둔다. gmail 은 보유 여부(`has_mail`)만 불리언으로 노출.
  자격증명도 **값이 아니라 파일 경로**만 표시한다(OpenObserve 사용자명은 예외 — 비밀번호와
  분리돼 있어 단독으로는 쓸모가 없다)
- 웹에서 서버 명령을 실행하는 버튼은 두지 않는다 — 복사만. 실행 경로에 인증·감사가
  없는 웹 트리거는 사고 표면이다

## 결정 기록

- 2026-08-24 · **관제탑은 070과 별도 페이지로.** OpenObserve 는 지표, 관제탑은 운영
  현황 + 진입점. 관리 기능 재구현 없이 각 도구 관리 화면으로 링크만 —
  "실작업은 스크립트, UI는 호출/진입" 원칙 유지.
- 2026-08-24 · ~~인증은 htpasswd(110의 2안)~~ → **쿠키 게이트로 교체**. nginx 계층에서
  잠그는 것과 새 포트 개방 없음은 유지. 교체 이유는 아래 두 항목.
- 2026-08-24 · **버그: `ERR_TOO_MANY_RETRIES` — nginx 절대 리다이렉트가 내부 포트를 노출.**
  nginx 가 `127.0.0.1:8081` 에 listen 하고 Cloudflare 터널 뒤에 있는데, 리다이렉트
  Location 을 `http://aitf.excusa.uk:8081/hub/` 로 만들었다. 브라우저가 공개 도메인의
  8081 포트로 접속을 재시도하다 실패 — 로그인 창조차 뜨지 않은 원인.
  **해결: 서버 블록에 `absolute_redirect off; port_in_redirect off;`** →
  Location 이 `/hub/` 상대 경로로 나간다. 터널·프록시 뒤 nginx 의 고전적 함정이며,
  `/git`·`/pages` 등 다른 경로의 디렉토리 리다이렉트에도 같이 적용된다.
- 2026-08-24 · **Basic 인증 불채택.** 브라우저가 자격증명 캐시·재시도를 자체 상태 머신으로
  처리해, 한 번 꼬이면 사용자가 프롬프트조차 못 보고 빠져나올 방법이 없다(운영 도구에
  치명적). 쿠키 게이트는 상태가 서버에 있어 진입 URL 재발급으로 언제든 복구된다.
  키 교체 = `map` 값과 진입 URL 만 바꾸면 되고, 기존 쿠키는 즉시 무효화된다.
- 2026-08-24 · 도메인·개강일은 `hub.env`(서버 전용)에서 주입 — 저장소에 실값 금지.
- 2026-08-24 · **디자인을 xAI 디자인 언어로 전면 교체** — 강사가 제공한 xAI 분석 스펙 기반.
  룰 정본은 [`web/hub/DESIGN.md`](../web/hub/DESIGN.md) (근흑 캔버스·필 버튼·웨이트 400
  단일·아이브로우·그림자 금지). 운영 도구 웹은 이후 전부 이 룰을 따르고,
  배포물·발표자료는 기존 design-spec 유지 — 두 체계는 섞지 않는다.
- 2026-08-24 · **shadcn/ui 는 구조·문법만 채택, 정적 구현** — 외부 요청 0의 단일 HTML
  원칙과 React 빌드가 충돌하므로 Navigation Menu·Card·Table·Badge·Progress·Chart 의
  형태를 CSS/vanilla JS 로 구현. 차트 팔레트는 xAI 악센트 4색 매핑. 페이지는 해시 탭
  4개(개요/학생/준비/운영)로 분할, 주차별 준비 체크리스트는 localStorage 저장.
- 2026-08-24 · **타이포그래피를 Paperlogy 로 교체.** xAI 원본의 mono 캡션 페이스를
  아이브로우·배지·라벨 전반에 쓰던 것을 강사가 "못생겼다"고 판단 — mono 는 코드·경로에만
  남기고, 나머지는 Paperlogy(한글) + 대문자 트래킹으로 아이브로우 성격을 유지한다.
  DESIGN.md §1 타이포그래피 표를 이에 맞춰 갱신했다.
- 2026-08-24 · 폰트는 **한글 음절 전체를 서브셋해 임베드**한다(woff2 135KB). 페이지 텍스트가
  JS 로 동적 생성돼 curriculum/build-html.py 의 "보이는 글자만 서브셋" 방식을 쓸 수 없다.
  `web/hub/build.py` 가 `index.src.html` → `index.html` 을 만든다.
- 2026-08-24 · **명령 목록에서 코드 원문을 감췄다.** 가로 스크롤바가 화면을 해치고 강사가
  읽지도 않는다 — 설명 한 줄 + 복사 버튼만 남기고 명령은 클립보드로만 전달한다.
- 2026-08-24 · 차트를 `라벨 | 트랙 | 값` **3열 그리드**로 재구성. 값 라벨을 절대 위치로
  띄우던 방식은 최대값 막대에서 카드 밖으로 삐져나갔다.
- 2026-08-25 · **주차별 계획을 커리큘럼 문서에서 자동 추출**로 전환. 하드코딩된 준비
  목록만으로는 "이번 주에 뭘 하는지"를 알 수 없었다. `build-weeks.py` 가
  `### N주 —` 절을 파싱해 목표·역량·기술·진행 단계·준비 항목을 뽑는다.
  파싱에서 걸린 두 가지: ⓐ 본문 중간의 줄 첫머리 `**강조**`(5주차)를 필드 경계로
  쓰면 잘린다 → 경계를 실제 라벨(진행·강사 준비)로 한정. ⓑ 라벨에 부제가 붙는
  경우(8주차 `**진행 · 전반 60분**`)와 같은 라벨이 여러 번 나오는 경우 → 라벨
  접두 매칭 + 다중 블록 결합. 12주 전부 정상 추출 확인.
  `build-weeks.py` 는 저장소 경로를 참조하므로 `/opt/scripts` 에 설치하지 않는다.
