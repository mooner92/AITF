## 왜 따로 만드나 — 070(OpenObserve)과의 관계

070은 **지표**(토큰·메모리·커밋 수의 시계열)를 담당한다. 그런데 수업을 운영하다 보면
지표가 아니라 **"내가 깔아둔 것들이 조용히 잘 돌고 있나 / 이번 주에 뭘 준비해야 하나 /
학생에게 나중에 줄 재료가 쌓이고 있나"**를 잊는다 — 자동 위키가 매주 쌓이고 있다는
사실 자체를 수업 중에 잊는 문제. 이건 대시보드 빌더로 만들 수 있는 화면이 아니라
**수업 운영 현황판**이므로 얇은 정적 페이지로 따로 둔다.

| | OpenObserve (070) | 관제탑 (이 문서) |
|---|---|---|
| 내용 | 토큰·리소스·진도 시계열 | 서비스 생존 · 자동화 최근 실행 · 주차별 준비 · 학생 적립 · 바로가기 |
| 갱신 | 수업 중 1분 | 5분 (cron) |
| 성격 | 분석 | 한눈 확인 + 진입점(런처) |

관제탑에서 Gitea 관리자·OpenObserve·위키 3종·작품관으로 **바로 이동**한다 —
"모든 걸 여기서 관리"의 실체는 각 도구의 관리 화면으로 가는 문이다. 각 도구의
관리 기능을 웹 버튼으로 재구현하지 않는다(070의 기존 결정 유지 — 실작업은 스크립트).

## 구성

```
scripts/hub-status.sh   ── cron(5분) → /srv/hub/status.json 생성
web/hub/index.html      ── 배포 시 /srv/hub/index.html 로 복사
nginx location /hub/    ── 기존 서버 블록에 추가, htpasswd 인증(110의 2안 방식)
/opt/scripts/hub.env    ── DOMAIN=·COURSE_START= (서버에만 — 저장소에 실값 금지)
/opt/scripts/hub-notes.md ── 강사 수동 노트(외부 의존·결정 대기) → 페이지에 그대로 표시
```

### 페이지 구역

1. **서비스** — nginx·Gitea·docker·터널·OpenObserve 생존 (초록/빨강 점)
2. **자동화** — 토큰 수집·스냅샷·자동 위키·리허설 로그의 마지막 실행 시각.
   오래됐으면 노랑 경고. **자동 위키는 미구축 상태가 그대로 보인다** — 개강 전
   필수(130)인데 아직이라는 사실이 매일 눈에 밟히게 하는 것이 의도다
3. **이번 주** — `COURSE_START` 기준 주차 계산 + 그 주 강사 준비 목록
   (detailed-plan v8.5 강사 준비 항목을 페이지에 정적 내장 — 커리큘럼 바뀌면 같이 갱신)
4. **학생 적립 현황** — 계정별 커밋 수·작품 파일 수·마지막 활동. 12주차 포트폴리오
   재료가 실제로 쌓이는지 확인하는 자리
5. **바로가기** — Gitea 관리자(`/git/-/admin`)·위키 3종(120)·OpenObserve·작품관
6. **수동 노트** — hub-notes.md 원문 표시 (학원 IP·API 키·명단 등 외부 의존 메모)
7. **관리 명령** — 자주 쓰는 원라이너 복사 버튼 (실행은 터미널에서 — 웹에서 실행하지 않음)

## 보안

- `/hub/` 에 **nginx basic auth(htpasswd)** — 자격증명은 `/opt/scripts/hub-admin.txt`(600).
  110에서 검토한 2안 인증을 그대로 쓴다. 학생·외부인은 열람 불가
- `/srv/hub` 는 root:nginx 750 — 학생 로컬 계정이 status.json 을 직접 못 읽는다
  (다른 학생의 활동 시각·커밋 수가 담기므로)
- status.json 에 이름·gmail·비밀번호·토큰은 **절대 넣지 않는다** — 계정 ID와 집계 수치만
- 웹에서 서버 명령을 실행하는 버튼은 두지 않는다 — 복사만. 실행 경로에 인증·감사가
  없는 웹 트리거는 사고 표면이다

## 검증 기준

1. 무인증 접근 → 401
2. 학생 계정에서 `/srv/hub/status.json` 직접 읽기 → 거부
3. 서비스 하나를 내리면 5분 내 빨간 점으로 표시
4. cron 이 멈추면 페이지 상단에 "상태 파일이 오래됐습니다" 배너
5. status.json 에 이름·이메일·비밀번호가 없다

## 결정 기록

- 2026-08-24 · **관제탑은 070과 별도 페이지로.** OpenObserve 는 지표, 관제탑은 운영
  현황 + 진입점. 관리 기능 재구현 없이 각 도구 관리 화면으로 링크만 —
  "실작업은 스크립트, UI는 호출/진입" 원칙 유지.

- 2026-08-24 · 도메인·개강일은 `hub.env`(서버 전용)에서 주입 — 저장소에 실값 금지.
