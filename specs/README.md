## 운영자 결정 대기 (외부 게이트)

1. 부트 볼륨 백업 완료 여부 → 010
2. 인스턴스 관련 클라우드 공지의 정체 확인 (마감 있음) → 010
3. 학원 고정 IP 여부 → 030 인증 방식 분기
4. 수업 도메인 결정 → 030
5. 예상 인원·반 수 → 040 메모리 예산
6. 수업 주제 확정 → 055 / 090

## 스펙 문서 형식

각 스펙은 다음 섹션을 가진다:
`상태` / `목표` / `설계` / `작업 체크리스트` / `검증 기준` / `결정 기록(Decision Log)` / `비공개 참조`(민감 세부가 있는 경우 서버 내 위치만 명시)
