## 운영자 결정 대기 (외부 게이트)

1. 부트 볼륨 백업 (콘솔 1회 — 가급적 즉시)
2. **Cloudflare Access 앱 생성 → 030** ⚠️ mon·git이 현재 로그인 화면 공개 노출 상태
3. 학원 고정 IP 여부 → 030 (Bypass 정책 대상)
4. 학생 명단 → 040·060 일괄 생성
5. OpenAI·Google API 키 발급 → 050

## 스펙 문서 형식

각 스펙은 다음 섹션을 가진다:
`상태` / `목표` / `설계` / `작업 체크리스트` / `검증 기준` / `결정 기록(Decision Log)` / `비공개 참조`(민감 세부가 있는 경우 서버 내 위치만 명시)
