# 000 — 전체 아키텍처·원칙

**상태**: Approved · 2026-08-16

## 목표

코딩학원 AI 특강(12주)을 위한 공유 리눅스 서버 환경.
학생 개개인이 브라우저만으로 접속해 AI 코딩 에이전트(Codex/Gemini CLI)로 프로젝트를 만들고,
강사는 토큰 사용량·진도를 실시간 관측하며, 사고 시 학생 단위로 복구할 수 있어야 한다.

## 아키텍처

```
[학생 브라우저] ──(Cloudflare Zero Trust: IP Bypass)──▶ ssh.<domain> ─▶ 서버 sshd (브라우저 터미널)
                                                        git.<domain> ─▶ Gitea (127.0.0.1:3000)
[강사]        ──(Cloudflare Access: 이메일 OTP)──────▶ mon.<domain> ─▶ 모니터링 웹 (127.0.0.1:8080, 자체 인증)

서버 (OCI A1.Flex 4 OCPU/24GB, Oracle Linux 9, SELinux Enforcing)
├── 학생 계정 xN  — tmux 자동 진입, systemd slice 메모리 상한, sudo 없음
├── /opt/harness  — 교육용 에이전트 하네스 (root 소유 읽기 전용, 각 홈에 심링크)
├── /opt/template-home — 프로젝트 스켈레톤 + node_modules 사전 설치
├── Gitea         — 학생 1인 1저장소 + 반별 위키
├── tokmon        — tokscale 기반 토큰 수집(cron) + 모니터링 웹
└── /srv/snapshots — 수업 후 rsync --link-dest 증분 스냅샷
```

## 핵심 원칙

1. **학생 계정에 sudo를 절대 주지 않는다.** (wheel 금지)
2. **공용 서버 전제**: 이 서버에는 기존 운영 서비스가 함께 돈다. 기존 서비스를 중단·재시작·삭제하지 않으며, 학생 부하로부터 보호한다(메모리 상한·부하 테스트).
3. **루프백은 학생에게 방벽이 아니다.** 학생은 로컬 계정이므로 127.0.0.1 서비스에 접근 가능. 내부 서비스는 루프백 바인딩 **+ 인증**.
4. **SELinux는 끄지 않는다.** 막히면 `restorecon`/`semanage`로 푼다.
5. **잠금 순서 엄수**: 새 접속 경로 3중 검증 전에 기존 경로(포트 22)를 닫지 않는다.
6. **모든 파괴적 변경 전에 복구 지점**: 부트 볼륨 백업(전체) / 스냅샷(학생 단위).
7. **교육 우선 하네스**: AI가 조용히 고쳐주지 않고, 뭐가 왜 틀렸는지 쉬운 한국어로 먼저 설명하게 만든다.
8. **공개 저장소 정보 정책**: [SECURITY.md](../SECURITY.md) — 실제 값(IP·키·계정)은 서버 내 비공개 노트에만.
