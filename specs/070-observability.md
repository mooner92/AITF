# 070 — P6: 토큰 관측·모니터링 웹

**상태**: Draft · 차단: 050

## 목표

강사가 반 전체/개인별 토큰 사용량을 준실시간으로 본다. 학생별 분리 집계, 온라인 리더보드 미사용(로컬 전용).

## 설계

- **수집**: tokscale(로컬 로그 판독 CLI, 계정 불필요)을 cron으로 학생별 실행 → `/var/lib/tokmon/<계정>.json`
  - cron 주기: **수업 시간대 1분 / 평시 15분** (실제 시간표 확정 후 기입)
  - `/var/lib/tokmon`은 root 700 — 학생 상호 열람 차단. 학생 본인은 자기 계정에서 `tokscale` 직접 실행 시 본인 것만 보임.
- **모니터링 웹**: `127.0.0.1:8080` + systemd 서비스, 외부는 `mon.<domain>`(강사 OTP) 경유
  - **자체 인증 필수** — 학생이 로컬에서 `curl 127.0.0.1:8080` 가능하므로 루프백+Access만으로는 부족 (원칙 3). 간단한 토큰/로그인 1개면 충분.
  - 필요 뷰: 반 전체 실시간 / 개인별 / **수강 1차 vs 2차 비교**
- 관리자 버튼(유저 추가·초기화)은 후순위 — 실작업은 스크립트, UI는 호출 버튼일 뿐.
- 스크립트: [`scripts/collect-tokens.sh`](../scripts/collect-tokens.sh)
