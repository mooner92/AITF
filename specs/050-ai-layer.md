# 050 — P4: AI CLI·API 키

**상태**: In Progress · 모델 스택 확정 (2026-08-18) · 차단: API 키 발급

## 목표

모든 학생 계정에서 AI CLI가 즉시 동작. 키는 학생별 분리, 비용은 hard cap으로 상한.

## 모델 스택 (확정)

**단일 벤더 2모델**: 기본 = 저가 티어, 승급 = 중간 티어. 별도 벤더의 경량 모델은 쓰지 않는다.

| 역할 | 티어 | 단가(입력/출력, 100만 토큰) | 담당 |
|---|---|---|---|
| 기본 | 저가 | $0.20 / $1.20 | 학생과의 모든 대화, 수업의 ~90% |
| 승급 | 중간 | $2.00 / $12.00 | 하위 에이전트. 어려운 문제만 |

**12주 예상 총액 ~$97** (12명 × 12회 × 2시간, 캐싱 적용, 오차 3~6배 — 리허설 실측 후 확정).

### 이 조합을 고른 이유

- **저가 티어가 경쟁 저가 모델보다 앞선다** — 지능 지수, 속도, 컨텍스트(1.05M) 모두. 7월 말 80% 인하로 가격까지 최저.
- **같은 벤더 안에서 라우팅된다.** 다른 벤더의 경량 모델은 CLI가 프로세스부터 달라 "라우팅"이 아니라 도구 2개가 된다 — 10주차 리빌이 성립하지 않는다.
- **웹 검색이 CLI에 내장**돼 있어 검색용 별도 모델이 불필요하다.
- **10배 가격차**가 리빌·11주차 개선 레버·12주차 절감률의 재료가 된다.

## 설계

- **설치는 반드시 root 전역** (`sudo npm i -g`) — 운영자 계정의 npm prefix는 자기 홈(700) 아래라서 거기 설치하면 학생이 실행 불가:
  ```bash
  sudo npm i -g @openai/codex tokscale
  which codex   # /usr/bin 또는 /usr/local/bin 이어야 정상. /home/** 이면 잘못 설치된 것
  ```
- **키 발급**: 인원수만큼 개별 키 + **hard cap**. 위 예상액이 학생당 ~$8이므로 cap은 $20~30이면 충분히 여유롭다. 벤더가 하나라 대시보드도 하나.
- **키 주입**: 각 학생 `~/.bashrc`에 export, `chmod 600`. 계정 분리(홈 700)로 상호 열람 불가.
- 전역 gitignore(060)가 `.codex/` `.env`를 커밋에서 차단.
