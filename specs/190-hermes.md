## 0. 방침 — 짓지 않고 보여준다 (강사 결정 2026-08-26)

**학생에게 Hermes 설치·설정을 시키지 않는다.** 세팅에 시간이 오래 걸리고,
그 시간은 수업의 핵심이 아니다. 대신 **강사가 미리 구축해 두고 실제로 돌아가는
것을 보여준다** — 핵심 기능과 차별점만. 설치·응용은 학생이 알아서 찾아본다.

5주차 "well-made 하네스 해부"와 같은 방식이다. 짓는 게 아니라 **열어서 보는 것**이
학습이고, 그 뒤 자발적 탐색이 따라온다.

## 2. 수업에서 보여줄 차별점 — 이 넷만

기능 나열이 아니라 **"우리가 지금까지 배운 것과 뭐가 다른가"**로 보여준다.

### ⓐ 스스로 스킬을 쓴다 — 6주차의 완성형

복잡한 작업을 마치면 **재사용 가능한 스킬을 자동으로 만들어 둔다**("autonomous skill
creation after complex tasks", 쓰면서 스스로 개선). 6주차에 학생이 손으로 `SKILL.md` 를
쓴 직후 이걸 보여주면 — **"너희가 방금 손으로 한 걸 얘는 스스로 한다"** 가 성립한다.

### ⓑ 채팅창을 닫아도 계속 일한다

세션 기반 도구(지금까지 쓴 Codex)와의 결정적 차이. 8주차 "걸어두고 하교",
10주차 비동기 위임과 같은 개념이며, **그 개념의 실물**이다.

### ⓒ 기억이 쌓인다

대화가 아니라 **에이전트가 스스로 관리하는 메모리**. 11주차 위키 RAG 체험과
"AI가 읽기 좋은 글쓰기"로 이어진다.

### ⓓ Slack 이 곧 인터페이스

6주차에 학생은 봇 뼈대에 스킬을 꽂는다. Hermes 는 **게이트웨이가 내장**이라
같은 일을 설정 한 줄로 한다 — "직접 만들어 본 다음에 완성품을 보는" 순서.

## 3. 가오리 봇(150)과 무엇이 다른가

| | 가오리·거북이 (150) | Hermes (이 문서) |
|---|---|---|
| 하는 일 | 질문에 **답한다** (위키 RAG) | 시키면 **일한다** (도구 실행) |
| 상태 | 무상태 — 매번 새로 | 기억·스킬이 **쌓인다** |
| 목적 | "우리 반을 아는 답" | "위임하면 알아서 되는 것" |
| 위험 | 낮음 (읽기만) | **호스트에서 실행** — 4절 참조 |

**둘 다 둔다.** 겹치지 않는다.

## 4. 보안 — 이게 이 문서의 핵심 제약

**Hermes 는 호스트에서 도구를 실행한다.** Slack 에 붙이는 순간 그 채널의 누구나
Hermes 가 도는 계정 권한으로 명령을 실행할 수 있다. 040 의 계정 격리·sudo 차단이
이 경로로 우회될 수 있으므로 다음을 **전부** 지킨다.

- **전용 계정** — `opc` 도 학생 계정도 아닌 별도 계정으로만 실행
- **Docker 하드닝 필수** — 공식 제공(읽기 전용 루트·capability 제거·PID 제한)을 켠다
- **접근 금지 대상**: 학생 홈, `/opt/scripts`, 위키 원본(`/var/lib/wiki-build`),
  `/srv/hub`. 컨테이너에 마운트하지 않는다
- **전용 채널** — `#질문` 이 아니라 별도 채널. 채널 밖에서는 반응하지 않게
- **API 키 분리 + 자체 cap** — 학생 키와 다른 **OpenAI 키**. 폭주해도 수업이 멈추지 않게
- **인바운드 0 유지** — Slack 게이트웨이는 아웃바운드 연결이라 방화벽 무접촉(150 과 동일)

**학생 접근은 허용한다.** 위 격리가 서면 학생이 직접 시켜 보는 것이
6~7주차 핵심 경험("내가 시킨 걸 AI가 알아서 하고 스킬로 남긴다")이므로,
막기보다 안전하게 열어 두는 쪽이 교육적으로 낫다.

## 4-1. 모델 백엔드 — GPT 키를 쓴다 (2026-08-26 실측·확인)

세 경로를 다 확인했다.

| 경로 | 결론 | 근거 |
|---|---|---|
| **OpenAI API 키** | **채택** | Hermes 가 OpenAI 백엔드를 공식 지원. 이미 받을 키를 그대로 |
| Claude 구독 | **불가** | 2026-02 Anthropic 이 구독 OAuth 의 서드파티 사용을 **정책으로 금지**, 2026-04-04 시행. 구독 자격증명은 Claude Code·claude.ai 전용이고 서드파티는 API 키(종량제)만 |
| 이 서버 로컬 모델 | **불가** (아래) | 실측 13.3 tok/s |

### 이 서버에서 로컬 모델을 돌릴 수 있나 — 실측 결과 "위키는 되고 Hermes 는 안 된다"

LFM2.5-2.6B Q4_K_M 을 이 서버(aarch64 4코어·GPU 없음)에서 llama.cpp 로 직접 측정:

```
프롬프트 처리  42.6 tok/s
생성          13.3 tok/s      (4스레드 = 전 코어 사용)
```

| 용도 | 판정 | 이유 |
|---|---|---|
| **위키 서술 보강**(180) | **가능** | 2~4문장 ≈ 200토큰 ≈ **15초**. 일요일 20시 무인 실행이라 느려도 무관 |
| **Hermes 시연** | **불가** | 에이전트 한 턴은 사고 + 도구 호출 + 응답으로 쉽게 500~1500토큰 → **40~110초/턴**. 여러 턴 도는 작업이면 수 분. 10분 시연에 못 쓴다 |

**추가 제약**: 4스레드가 전 코어를 점유한다. 수업 중이면 학생 6명의 Codex 와
CPU 를 두고 다툰다 — 시연 하나 때문에 수업 전체가 느려진다.

**결론**: Hermes 는 GPT 키로 돌린다. 로컬 모델은 위키 보강용으로만 후보로 남긴다
(그마저도 GPT 키가 있으면 굳이 쓸 이유가 없다 — 150 부록 참조).

## 5. 수업 배치

| 주차 | 쓰임 | 시간 |
|---|---|---|
| **6주** | 학생이 `SKILL.md` 를 만든 **직후** ⓐ 시연 — "얘는 스스로 만든다" | 10분 |
| **7주** | 에이전틱 실물로 ⓑ·ⓓ — 도구를 쓰는 AI | 10분 |
| 10주 | 리마인드 목록에 포함 (쓸지는 학생 선택) | — |

**10주차 Paseo 는 그대로 둔다.** Paseo 는 학생 각자가 자기 프로젝트를 위임하는
도구고, Hermes 는 반이 함께 보는 상시 에이전트다. 개념(비동기 위임)은 겹치지만
역할이 다르므로 대체하지 않는다.

**"이번 주에 나온 것"(갈래 B) 소재로도 좋다** — MIT 오픈소스이고 실제로 널리 쓰이는
물건이라, 학생이 스스로 찾아볼 대상으로 적합하다.

## 6. 학생에게 주는 것 — 링크 하나

설치 안내서를 만들지 않는다. 시연 후 위키 `concepts/hermes.md` 에
**공식 저장소 링크 + 무엇이 다른지 3줄**만 남긴다. 관심 있는 학생이 직접 판다.

## 8. 검증 기준

1. Hermes 컨테이너에서 학생 홈·`/opt/scripts`·위키 원본에 **접근 불가**
2. 컨테이너에서 sudo·권한 상승 **불가**
3. 지정 채널 밖 멘션에 **무반응**
4. 시연 작업 후 스킬 파일이 **실제로 생성됨** (없으면 시연 시나리오를 바꾼다)
5. API 사용량이 학생 키와 **분리 집계**됨
6. 컨테이너를 죽여도 수업의 다른 부분이 **영향 없음**

## 결정 기록

- 2026-08-26 · **설치·설정을 수업에서 다루지 않는다.** 미리 구축해 두고 핵심 차별점만
  보여준다. 세팅 시간이 길고 수업의 핵심이 아니며, 5주차 "하네스 해부"에서 이미
  "짓지 않고 열어 보는" 방식이 효과적임을 전제한다. 설치·응용은 학생 자발 탐색.
- 2026-08-26 · **가오리 봇과 둘 다 둔다.** 답하는 봇(무상태·읽기)과 일하는 에이전트
  (기억·실행)는 성격이 달라 겹치지 않는다.
- 2026-08-26 · **10주차 Paseo 를 대체하지 않는다.** 개념은 겹치지만 Paseo 는 학생
  개인 위임 도구, Hermes 는 반 공용 시연 대상이다.
- 2026-08-26 · **전용 계정 + Docker 하드닝을 필수 조건으로 못박음.** 호스트 도구 실행이
  Slack 채널을 통해 열리므로, 이 격리 없이는 040 의 계정 분리가 무의미해진다.
- 2026-08-26 · 구축 시점을 **4~5주차**로. 개강 전에는 1~3주차 자료가 우선이고,
  Hermes 는 6주차 시연이므로 시간 여유가 있다.
- 2026-08-26 · **백엔드는 OpenAI API 키.** Claude 구독은 2026-02 정책 변경(2026-04-04 시행)으로
  서드파티 도구에서 쓸 수 없다 — 구독 OAuth 는 Claude Code·claude.ai 전용. 로컬 모델은
  이 서버 실측 13.3 tok/s 라 에이전트 시연에 부적합(한 턴 40~110초)하고, 전 코어를 점유해
  수업 중 학생 Codex 와 경합한다.
