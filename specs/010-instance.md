## 현재 상태 (실사)

- VM.Standard.A1.Flex **4 OCPU / 24GB** — Always Free 최대치. 셰이프 변경 불필요.
- 루트 파일시스템 29.5G 중 **96% 사용(잔여 1.4G)** — 이대로는 P3 이후 진행 불가.
- 단, 부트 볼륨은 200G인데 파티션이 44.5G만 사용 → **~155G 미할당**. 콘솔 작업 없이 서버 내 확장 가능.
- 즉효 정리 대상: npm 캐시 ~8.3G, docker 빌드 캐시 ~0.8G.

## 8/18의 의미 — 운영자 결정 (2026-08-16)

**셰이프는 현행 4 OCPU/24GB 유지, 변경하지 않는다.** 서버 스펙은 서버에서 조회되는 그대로를 기준으로 한다.
**8/18은 "서버 세팅 완료" 목표일**이다 — 이 날까지 P0~P7 인프라가 서 있어야 한다.

> 참고: Always Free 한도 반감(→2/12) 및 8/18 집행 보도가 있다 ([InfoQ](https://www.infoq.com/news/2026/07/oracle-cloud-free-tier-limits/)).
> 운영자 계정 기준으로는 해당 없음으로 판단(운영자 확인). 만일에 대비한 복구 지점이 부트 볼륨 백업이다.
