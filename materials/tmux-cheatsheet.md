# 터미널 생존 키 8개 (tmux)

> 접속하면 자동으로 작업 화면(tmux)에 들어와 있어요. 마우스는 안 씁니다 — 이 8개면 충분해요.

| 하고 싶은 것 | 키 | 메모 |
|---|---|---|
| 위로 스크롤 (지나간 내용 보기) | `Ctrl-b` 뗐다가 `[` → 방향키·`PgUp` | 다 봤으면 `q` |
| 스크롤 모드에서 나오기 | `q` | 이걸 안 눌러서 "멈췄어요"가 제일 많음 |
| 실행 중인 것 멈추기 | `Ctrl-c` | AI가 너무 길게 말할 때도 |
| 화면 지우기 | `Ctrl-l` | 지워도 스크롤에는 남아 있음 |
| 새 창 열기 | `Ctrl-b` 뗐다가 `c` | 창은 아래 숫자로 표시 |
| 다음/이전 창 | `Ctrl-b` 뗐다가 `n` / `p` | 숫자로 바로: `Ctrl-b` `0`~`9` |
| 인터넷 끊겼을 때 | 그냥 다시 접속 | 하던 작업 그대로 있음 (tmux가 지켜줌) |
| 이전 명령 다시 쓰기 | `↑` | 수정해서 Enter |

**규칙 하나**: `Ctrl-b`는 "누르고 뗀 다음" 다음 키. 동시에 누르는 게 아니에요.
