# 내 저장소

12주 동안 만드는 모든 것이 여기 쌓여요. 저장소는 이거 하나 —
새 프로젝트는 **폴더**로 늘어납니다.

```
project/
  README.md        ← 지금 읽는 파일
  MY-SERVER.md     ← 내 포트·주소 (자동 생성 — 고치지 마세요)
  rules/           ← 규칙 문서. 수업이 진행되면 여기 파일이 늘어나요
  profile_card/    ← 1주차부터, 매주 폴더가 하나씩
  …
  public/          ← 작품관. 여기 넣은 것만 웹에 보여요
```

## 폴더 이름은 규칙이 있어요

`rules/naming.md` 를 보세요. 요약: **영어 소문자 + 밑줄, 동사_명사, 짧게.**

## 저장하는 법

```bash
git add .
git commit -m "한 일을 한 줄로"
git push
```

## rules/ 폴더는 뭐예요?

선생님이 수업 진도에 맞춰 넣어주는 규칙 문서예요. 새 파일이 생기면
열어 보고, 다음 커밋에 같이 올리면 돼요. 이 문서들은 수료할 때
프로젝트와 함께 내 GitHub 로 그대로 가져갑니다.
