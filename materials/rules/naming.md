# 폴더 이름 규칙

> 이 문서는 선생님이 관리해요. 고쳐도 다음 배포 때 원래대로 돌아갑니다.

이 저장소는 12주 동안 쓰는 **하나뿐인 저장소**예요. 매주 새 걸 만들 때마다
저장소를 새로 만들지 않고, **폴더를 하나 추가**합니다.

## 규칙 세 가지

1. **영어 소문자 + 밑줄(`_`)만** — 띄어쓰기, 한글, 대문자 없이
2. **동사_명사** 꼴로 — 뭘 했는지가 이름에 보이게
3. **짧게** — 두 단어면 충분해요

| 좋은 예 | 나쁜 예 | 왜 |
|---|---|---|
| `use_skills` | `스킬써보기` | 한글은 터미널에서 다루기 불편해요 |
| `make_bot` | `MakeBot` | 대문자 섞으면 오타가 늘어요 |
| `remake_slides` | `my project 3` | 띄어쓰기는 명령어를 깨뜨려요 |

## 주차별 폴더 이름 (미리 보기)

| 주 | 폴더 | 만드는 것 |
|---|---|---|
| 1 | `profile_card` | 내 프로필 카드 |
| 3 | `remake_slides` | 학교 발표자료 다시 만들기 |
| 4 | `tune_harness` | 내 규칙이 들어간 에이전트 |
| 5 | `use_skills` | 스킬로 만든 포스터·슬라이드 |
| 6 | `make_bot` | 내 스킬이 들어간 봇 |
| 7 | `use_browser` | 웹에서 모은 자료 정리 |
| 9~12 | `final_project` | 팀 프로젝트 |

주차마다 선생님이 그날 폴더 이름을 알려줘요. 자유 작업은 이름을 직접 짓되
위 세 규칙만 지키면 됩니다.
