# 커밋 규칙

> 이 문서는 선생님이 관리해요. 고쳐도 다음 배포 때 원래대로 돌아갑니다.

커밋은 "여기까지는 안전하다"는 **저장 지점**이에요. 게임 세이브와 같아요 —
자주 찍을수록 되돌아갈 곳이 많아집니다.

## 언제 커밋하나요

- **뭔가 하나가 돌아가게 됐을 때** — 완벽할 때가 아니라, 동작할 때
- 수업이 끝날 때는 **반드시 한 번** — 그날 작업이 통째로 남아요
- 설정(AGENTS.md 같은 것)을 고치기 **직전** — 망치면 돌아올 곳

## 메시지는 이렇게

```
git commit -m "프로필 카드에 전적 검색 추가"
```

- **한 일을 한 줄로.** 나중에 목록만 봐도 뭘 했는지 알게
- "수정", "커밋", "asdf" 같은 메시지는 금지 — 미래의 내가 읽을 수 없어요
- 한글로 써도 됩니다

| 좋은 예 | 나쁜 예 |
|---|---|
| `발표자료 디자인 규칙 적용` | `수정함` |
| `봇에 급식 메뉴 기능 추가` | `ㅁㄴㅇㄹ` |
| `AGENTS.md 말투 규칙 실험` | `커밋` |

## 세 줄이면 끝

```bash
git add .
git commit -m "한 일을 한 줄로"
git push
```

push 까지 해야 서버(Gitea)에 올라가요. 커밋만 하면 내 자리에만 있습니다.
