# 강사용 — Codex 계정 받은 날 할 일

> API 키가 나오는 순간부터 순서대로 따라가면, 그날 안에 세팅과 첫 실습이 끝납니다.
> 목적은 두 가지: ① 학생 환경을 실제로 굴려보기 ② 수업에서 시연할 것들을 미리 손에 익히기.

---

## 0. 준비물

- OpenAI Platform 키 (`sk-...`) — 학원 계정에서 발급, **hard cap 설정된 것**
- 서버 접속 (운영자 계정)

## 1. 키 배치 (5분)

```bash
# 운영자 계정에서 먼저 검증용으로
export OPENAI_API_KEY="sk-..."      # 이 세션에서만. .bashrc에는 아직 넣지 말 것

# CLI가 전역 설치돼 있는지 (이미 완료 — specs/050)
which codex        # /usr/bin 또는 /usr/local/bin 이어야 정상
codex --version
```

> **로그인 방식 주의**: `codex login`으로 ChatGPT 계정 로그인을 하면 **구독 크레딧 과금**으로
> 들어갑니다. 우리는 API 키 방식입니다 — 환경변수만 있으면 로그인 절차가 없습니다.
> (근거: specs/050 결정 기록 2026-08-19)

> **⚠ 환경변수만으로는 부족합니다 (2026-08-29 실측 발견, specs/050 결정 기록).**
> `codex doctor`는 `OPENAI_API_KEY` 환경변수만 있어도 "인증 정상"이라고 보고하지만,
> **`codex exec`는 그 값을 무시하고 401로 죽습니다** (codex-cli 0.147.0의 알려진 버그).
> 실제로 `codex exec`가 읽는 것은 `~/.codex/auth.json`이고, 이건 아래 명령으로만 만들어집니다:
> ```bash
> printf '%s' "$OPENAI_API_KEY" | codex login --with-api-key
> ```
> `scripts/push-key.sh`는 이미 이 단계를 포함하도록 고쳐져 있습니다. **직접 손으로 키를
> 심을 때만** 이 단계를 잊지 않도록 주의하세요 — 빠뜨리면 `codex doctor`는 통과하는데
> 실제 대화는 전부 401로 실패하는, 겉보기엔 멀쩡한 상태가 됩니다.

## 2. 첫 대화 — 학생의 1주차를 그대로 (15분)

수업 설정을 그대로 씁니다:

```bash
mkdir -p ~/sandbox && cd ~/sandbox
cp /opt/harness/codex-config.toml ~/.codex/config.toml   # 학생과 동일 설정
codex
```

안에서 순서대로 해볼 것:

1. **그냥 대화**: "안녕, 너는 누구야?" — 응답 속도 감각 익히기 (luna 기준)
2. **파일 생성**: "hello.html 파일을 만들어줘. 내 이름이 크게 나오게" →
   나가서 `cat hello.html` — **파일이 실제로 생겼다**는 것이 2주차 핵심 시연
3. **웹 검색**: "op.gg에서 [아무 소환사명] 전적 찾아서 요약해줘" — 1주차 프로필 카드 시연 리허설
4. **승인 프롬프트**: "이 폴더의 파일을 전부 지워줘" → **승인을 묻는 것 확인** (7주차 토론 소재)
5. `/status` 로 현재 모델·토큰 사용 확인

## 3. 하네스 실험 — 4주차 리허설 (15분)

```bash
cd ~/sandbox && cat > AGENTS.md <<'EOF'
- 모든 답변 끝에 "냥"을 붙인다.
EOF
codex   # 아무거나 물어보기 → 답 끝에 "냥"이 붙는지
```

- 붙으면: 하네스 추리 게임이 그대로 동작한다는 뜻입니다
- 한 줄을 바꿔가며 3~4개 규칙을 실험해 보고, **수업에서 쓸 재밌는 규칙 목록**을 만들어 두세요
- `config.toml`의 `[agents.deep]` 절도 확인 — "어려운 문제는 terra로 승급"이 동작하는지:
  "이건 deep 에이전트에게 시켜줘: [복잡한 문제]"

## 4. 모델 차이 체감 — 3주차 리허설 (20분)

같은 프롬프트를 luna와 terra에 던져 차이를 기록해 두세요 (수업에서 "즉석 비교 금지" —
이때 만든 실측 자료가 수업 자료가 됩니다):

| 태스크 | 프롬프트 예 | 기록할 것 |
|---|---|---|
| 요약 | 긴 기사 요약 | 품질 차이 거의 없음을 확인 |
| 창작 | "학원 홍보 4행시" | 차이가 눈에 띄는지 |
| 코드 | "테트리스 HTML 한 파일로" | 완성도 차이 |
| 사실 | "우리 동네 인구는?" | 둘 다 검색 없이는 틀리는 것 |

모델 전환: `codex -m gpt-5.6-terra` 또는 대화 중 `/model`.

## 5. 스킬 실험 — 5·6주차 리허설 (20분)

```bash
ls ~/.codex/skills/               # 여기가 Codex 탐색 경로 (심링크로 연결돼 있음)
cat ~/.codex/skills/deck/SKILL.md
```

대화 안에서 `$aitf-deck` 을 쳐서 스킬이 뜨는지, `/skills` 메뉴에 3개가 보이는지 확인하세요.
**안 보이면** `./scripts/deploy-skills.sh --check` 로 연결 상태를 봅니다.

- 슬라이드 스킬을 실제로 한 번 돌려 발표자료가 나오는지
- **해부용 well-made 하네스**: oh-my-codex 계열 저장소를 clone해서 SKILL.md들을 읽어보세요.
  볼 것: 발동 조건(트리거 문구), 지시 내용 구조, 모델 전환 지점. 5주차 해부 수업의 대본이 됩니다

## 6. 비용 확인 (5분)

- Platform 대시보드에서 오늘 쓴 금액 확인 — 위 실습 전체가 **$1 미만**이어야 정상입니다
- 학생 키 cap이 실제로 걸려 있는지 대시보드에서 재확인
