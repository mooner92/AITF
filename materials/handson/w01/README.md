# handson/w01 — 1주차 핸즈온 문장

수업 중 프로젝터에 띄우거나 복사해 쓰는 문장 모음. 슬라이드의 코드블록과 1:1 대응한다.
번호 = 수업에서 쓰는 순서. 파일 하나 = 한 번에 쓰는 한 덩어리.

| 파일 | 쓰는 장면 | 슬라이드 |
|---|---|---|
| 01-프로필카드.txt | 프로필 카드 첫 지시 | "이렇게 시켜보세요" |
| 02-고치기.txt | 수정 반복 (한 줄씩 따로) | "마음에 안 들면 다시 시키면 돼요" |
| 03-검색없이.txt | 할루시네이션 시연 (강사만) | "그런데 검색을 안 하면 어떨까요" |
| 04-오늘정리.txt | 핸드오프 의식 | "마지막으로 이렇게 시켜요" |

원칙: 학생이 칠 문장은 짧게 유지한다. 긴 문장은 강사가 복사해 보여주고,
짧고 중요한 것만 학생이 직접 치게 한다 — 타이핑 병목이 흐름을 끊지 않게.
