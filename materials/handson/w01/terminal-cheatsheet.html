터미널 명령어 정리

오늘 서버에 접속해서 실제로 써본 명령어 다섯 개예요. 순서대로 다시 읽어보세요.

오늘 쓴 명령어

ssh 내 컴퓨터에서 학교 서버로 접속합니다. 계정 카드의 아이디와 비밀번호를 씁니다.
$ ssh 내아이디@서버주소Password: (쳐도 화면엔 안 보여요)

처음 접속할 때 "이 서버를 신뢰합니까?" 라고 물으면 yes를 입력합니다.

ls 지금 있는 폴더 안에 뭐가 들어있는지 봅니다. list의 줄임말이에요.
$ lsAGENTS.md public README.md work
cd 다른 폴더 안으로 들어갑니다. change directory의 줄임말이에요.
$ cd project(project 폴더 안으로 이동)
cat 파일을 열지 않고 내용을 화면에 그대로 보여줍니다.
$ cat README.md(파일 내용이 그대로 출력됨)
nano 파일을 열어서 직접 고치는 편집기입니다.
$ nano README.md(편집 화면이 뜸)

저장은 Ctrl+O → Enter, 나가기는 Ctrl+X. 화면 맨 아래에 항상 단축키가 떠 있어요.

오늘 자주 만난 실수

is 라고 쳐서 "명령어를 찾을 수 없습니다"가 떴어요.
→ ls의 오타예요. 터미널은 철자가 하나만 달라도 다른 명령어로 인식해요.
nano 편집 화면 안에서 y나 다른 글자를 쳤는데 "명령어를 찾을 수 없습니다"가 떴어요.
→ nano를 이미 나온 뒤에 친 거예요. 화면 아래 초록 안내줄이 없으면 지금 편집기 밖이라는 뜻이에요.
수업용 지시서 파일(AGENTS.md)을 nano로 고치려는데 Permission denied가 떴어요.
→ 일부러 막아둔 파일이라 정상이에요. 학생 계정은 이 파일을 못 고치게 돼 있어요.

기억할 것 하나

터미널은 오타에 아주 예민해요. 안 될 땐 오류 메시지를 천천히 읽고, 방금 친 글자를 한 글자씩 확인하는 습관을 들이면 좋아요.
