Codex 계정 받은 날, 이 순서대로

API 키가 나오는 순간부터 따라가면 그날 안에 세팅과 첫 실습이 끝납니다. 목적은 두 가지 — 학생 환경을 실제로 굴려보기, 수업에서 시연할 것들을 미리 손에 익히기.

1

키 배치 5분

# 운영자 계정에서 검증용으로. .bashrc에는 아직 넣지 않는다
export OPENAI_API_KEY="sk-..."

# CLI 전역 설치 확인 (이미 완료 — specs/050)
which codex     # /usr/bin 또는 /usr/local/bin 이어야 정상
codex --version
과금 함정

codex login으로 ChatGPT 계정 로그인을 하면 구독 크레딧 과금으로 들어갑니다. 우리는 API 키 방식입니다 — 환경변수만 있으면 로그인 절차가 없습니다. (근거: specs/050 결정 기록 2026-08-19)

2

첫 대화 — 학생의 1주차 그대로15분

mkdir -p ~/sandbox && cd ~/sandbox
cp /opt/harness/codex-config.toml ~/.codex/config.toml   # 학생과 동일 설정
codex
  1. 그냥 대화 — "안녕, 너는 누구야?" 응답 속도 감각 익히기 (luna 기준)
  2. 파일 생성 — "hello.html 파일을 만들어줘" → 나가서 cat hello.html. 파일이 실제로 생겼다는 것이 2주차 핵심 시연입니다
  3. 웹 검색 — "op.gg에서 [소환사명] 전적 찾아서 요약해줘" — 1주차 프로필 카드 리허설
  4. 승인 프롬프트 — "이 폴더 파일을 전부 지워줘" → 승인을 묻는 것 확인 (7주차 토론 소재)
  5. /status 로 현재 모델·토큰 사용 확인
3

하네스 실험 — 4주차 리허설15분

cd ~/sandbox && cat > AGENTS.md <<'EOF'
- 모든 답변 끝에 "냥"을 붙인다.
EOF
codex   # 아무거나 물어보기 → 답 끝에 "냥"이 붙는지
  • 붙으면 하네스 추리 게임이 그대로 동작한다는 뜻입니다
  • 규칙을 3~4개 바꿔가며 실험하고, 수업에서 쓸 재밌는 규칙 목록을 만들어 두세요
  • config.toml의 [agents.deep] 절 확인 — "이건 deep 에이전트에게 시켜줘: [복잡한 문제]"로 terra 승급이 동작하는지
4

모델 차이 실측 — 2주차 리허설20분

같은 프롬프트를 luna와 terra에 던져 차이를 기록해 두세요. 수업 중 즉석 비교는 금지 — 이때 만든 실측 자료가 수업 자료가 됩니다.

태스크프롬프트 예기록할 것
요약긴 기사 요약품질 차이 거의 없음을 확인
창작"학원 홍보 4행시"차이가 눈에 띄는지
코드"테트리스 HTML 한 파일로"완성도 차이
사실"우리 동네 인구는?"둘 다 검색 없이는 틀리는 것

모델 전환: codex -m gpt-5.6-terra 또는 대화 중 /model.

5

스킬 실험 — 5주차 리허설20분

ls /opt/harness/skills/           # 설치된 슬라이드·스토리북 스킬
cat /opt/harness/skills/slides/SKILL.md
  • 슬라이드 스킬을 실제로 한 번 돌려 발표자료가 나오는지 확인
  • 해부용 well-made 하네스: oh-my-codex 계열 저장소를 clone해 SKILL.md들을 읽으세요. 볼 것 — 발동 조건(트리거 문구) · 지시 내용 구조 · 모델 전환 지점. 5주차 해부 수업의 대본이 됩니다
