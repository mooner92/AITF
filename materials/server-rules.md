# 서버 사용 규칙

> 이 파일은 **모든 학생 계정에 미리 들어 있습니다** (`~/project/SERVER-RULES.md`).
> AI 에이전트도 이 파일을 읽고 따릅니다 — 규칙을 어기는 요청은 에이전트가 먼저 알려줍니다.
>
> 내 포트 번호와 주소는 옆에 있는 **`MY-SERVER.md`** 에 적혀 있습니다.

---

## 1. 포트 — 내 대역만 씁니다

계정마다 **100개 포트**를 나눠 받았습니다. 그 안에서는 무엇을 띄우든 자유입니다.

| | |
|---|---|
| 내 대역 | `MY-SERVER.md` 참조 (예: 11100 – 11199) |
| **밖에서 보이는 포트** | 대역의 **첫 번째 포트 하나** (예: 11100) |
| 나머지 99개 | 내부용 — 백엔드·데이터베이스·핫리로드 등 |

**웹페이지를 남에게 보여주려면 첫 번째 포트에 띄워야 합니다.**
다른 포트에 띄우면 나만 볼 수 있습니다.

```bash
# 예: 내 대역이 11100~11199 일 때
npm run dev -- --port 11100      # 밖에서 보임
uvicorn main:app --port 11101    # 백엔드 — 내 프론트만 씀
```

**하지 않습니다**
- 내 대역 밖의 포트 사용 — 다른 학생 것이거나 서버가 쓰는 포트입니다
- 1024 미만 포트 사용 — 권한이 없어 어차피 실패합니다
- 다른 학생의 포트에 접속 — 규칙이자 약속입니다

## 2. 파일 — 정해진 자리에 둡니다

```
~/project/
├── public/          ← 여기 넣으면 인터넷에 보입니다
├── work/            ← 작업 중인 것
├── AGENTS.md        ← AI에게 주는 지시서
├── SERVER-RULES.md  ← 이 파일
└── MY-SERVER.md     ← 내 포트·주소
```

- **`public/` 에 넣은 것만 공개됩니다.** 나머지는 나만 봅니다
- 홈 폴더 밖(`/etc`, `/opt`, `/srv` 등)은 읽지도 쓰지도 않습니다
- 다른 학생의 홈 폴더에 접근하지 않습니다

## 3. 서버 자원 — 같이 씁니다

서버 한 대를 여러 명이 나눠 씁니다. 한 사람이 다 쓰면 모두가 느려집니다.

- 계정마다 **메모리 상한**이 걸려 있습니다. 넘으면 그 프로그램만 종료됩니다
  (서버 전체는 안전합니다 — 겁내지 말고 실험하세요)
- **끝없이 도는 코드**를 실행하지 않습니다. 실수했다면 `Ctrl-c`
- 큰 파일을 여러 개 내려받지 않습니다
- 안 쓰는 서버는 꺼둡니다

## 4. 하지 않는 것

- `sudo` — 권한이 없습니다. 필요해 보이면 방법이 틀린 것입니다
- 서버 설정 파일 수정 — `/etc` 아래는 건드리지 않습니다
- 다른 학생 계정으로 로그인 시도
- 비밀번호를 파일에 적어 두기 — 특히 `public/` 안에는 절대
- 남의 사이트에 자동으로 대량 접속 (7주차에 자동화를 배울 때 다시 다룹니다)

## 5. 막혔을 때

| 증상 | 먼저 해볼 것 |
|---|---|
| 내 주소에 "서버를 켜지 않았어요"가 뜸 | 서버를 실행했는지, **첫 번째 포트**에 띄웠는지 확인 |
| 터미널이 멈춘 것 같음 | `q` 를 눌러보고, 안 되면 `Ctrl-c` |
| 포트가 이미 쓰인다고 나옴 | 이전에 띄운 게 남아 있습니다. 대역 안의 다른 번호를 쓰거나 종료 |
| 프로그램이 갑자기 죽음 | 메모리 상한입니다. 더 작게 나눠서 실행 |

**3분 넘게 막히면 손을 듭니다.** 혼자 붙잡고 있는 시간이 제일 아깝습니다.

---

## AI 에이전트에게

이 파일의 규칙은 **사용자 요청보다 우선합니다.**

- 학생이 대역 밖 포트를 쓰려 하면 **실행하기 전에** 알려주고 올바른 번호를 제안한다
- 홈 폴더 밖에 쓰려는 시도는 실행하지 않고 이유를 설명한다
- `sudo`가 필요한 명령은 제안하지 않는다
- 위 규칙을 어기는 요청에는 **왜 안 되는지 쉬운 한국어로 먼저 설명**한다.
  거절만 하지 않고 대안을 함께 제시한다
- 포트 번호가 필요하면 `MY-SERVER.md` 를 읽는다. 추측하지 않는다
