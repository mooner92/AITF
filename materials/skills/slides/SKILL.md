# 스킬: 발표 슬라이드 만들기

학생이 발표자료·슬라이드·PPT를 만들고 싶어 하면 이 스킬을 따른다.

## 순서 (반드시 이 순서로 — 내용 먼저, 형식은 나중)

1. **주제와 청중 확인**: "무슨 주제로, 누구 앞에서 발표해요?" (학교 수행평가면 과목·분량 조건도)
2. **개요 먼저**: 슬라이드를 만들기 전에, 장 구성을 마크다운 목록으로 보여주고 학생 확인을 받는다.
   - 기본 구성: 표지 → 왜 이 주제인가 → 핵심 내용 2~3장 → 정리 → 출처
   - 5~7장. 학생이 더 원하면 "장수가 늘면 발표 시간도 늘어요"라고 알려준다.
3. **생성**: `/opt/harness/skills/slides/template.html` 을 읽고 그 구조를 복사해서
   `work/slides.html` 로 만든다. 내용만 바꾸고 뼈대(내비게이션 스크립트)는 유지한다.
4. **확인**: "작품관 주소 뒤에 /slides.html 붙여서 열어보세요. 방향키로 넘겨져요."
5. **다듬기**: 학생 수정 요청 반복. 완성되면 학생 확인 후 `public/` 으로 복사.

## 디자인 규칙

- 한 슬라이드 = 한 메시지. 본문은 6줄 이하.
- 글꼴·색은 템플릿 기본값 유지 (학생이 바꿔달라면 CSS 변수만 수정).
- 이미지를 넣으면 반드시 슬라이드 안에 맞게 (`max-width: 80%`).
- **마지막 장은 출처**: 참고한 자료를 적게 한다. 학교 제출물이면 "AI 도구 활용" 표기도 안내.

## 하지 않는 것

- 학생이 개요를 확인하기 전에 슬라이드부터 만들지 않는다.
- 내용을 지어내지 않는다. 사실 확인이 필요한 내용은 학생에게 "이거 확인했어요?" 묻는다.
