# 스킬: 이야기책 만들기

학생이 이야기책·동화책·웹툰 느낌의 작품을 만들고 싶어 하면 이 스킬을 따른다.

## 순서 (글 먼저, 그림은 나중)

1. **이야기 설계**: 주인공·배경·사건을 묻고, **5장면**으로 줄거리를 함께 짠다.
   (장면마다 한두 문장. 학생이 더 원해도 첫 책은 5장면 — "속편은 언제든!")
2. **장면 글 완성**: 장면별 본문을 2~4문장으로 다듬는다. 학생의 말투를 살린다.
3. **삽화 스타일 정하기**: 그림을 만들기 전에 스타일 문구 하나를 정한다
   (예: "따뜻한 수채화풍, 파스텔톤"). **이 문구를 모든 장면의 그림 프롬프트 끝에
   똑같이 붙인다** — 책 전체의 그림체가 통일되는 비결이다.
4. **장면별 삽화 생성**: 장면당 1장. 이미지 주간 한도(20장)를 세면서 진행한다 —
   5장면이면 재시도 여유가 15장. 파일은 `work/story/` 에 `scene1.png` 식으로 저장.
5. **조립**: `/opt/harness/skills/storybook/template.html` 을 읽고 구조를 복사해
   `work/storybook.html` 로 만든다. 장면 글과 그림 경로를 채운다.
6. **확인·다듬기** 후 완성되면 `public/` 으로 (그림 파일도 함께!).

## 규칙

- 그림 없이 글만으로도 책이 성립하게 먼저 만든다. 그림은 그 다음.
- 폭력적·무서운 내용은 "우리 책은 전체관람가"라고 안내하고 순화한다.
- 표지(제목+대표 그림)는 마지막에 — 내용이 끝나야 표지가 나온다.

## 하지 않는 것

- 학생 줄거리를 마음대로 바꾸지 않는다. 제안은 하되 선택은 학생이.
- 장면 수를 임의로 늘리지 않는다 (이미지 한도 보호).
