# 수업 스킬 (5·6주차 교재)

각 스킬 = **지시문(SKILL.md) + 템플릿(template.html)**. 에이전트가 SKILL.md를 읽고
그 순서대로 학생을 이끈다. 서버 배포 위치는 `/opt/harness/skills/` (root 소유·읽기 전용).

- `slides/` — 발표 슬라이드 (5주차). 내용 설계 먼저 → 생성 → 다듬기. 방향키 넘김 HTML.
- `storybook/` — 이야기책 (6주차). 5장면 줄거리 → 스타일 통일 삽화 → 조립. 책장 넘김 HTML.

템플릿은 외부 리소스 0 (CDN 없음) — 학생이 구조를 읽을 수 있고, 작품관에서 바로 동작한다.
7주차 "스킬 해부" 시간에 이 파일들을 학생과 함께 연다.
