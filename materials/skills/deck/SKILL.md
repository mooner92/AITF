# 스킬: 발표자료 만들기 (AITF 스타일)

발표자료·슬라이드·PPT를 만들어 달라는 요청이면 이 스킬을 따른다.
결과물은 **파일 하나짜리 HTML**이다. 방향키로 넘기고, 인터넷 없이 열리고, 링크로 공유된다.

> 이 파일은 3주차 수업에서 학생과 함께 연다. **"선생님 자료가 늘 비슷해 보이는 이유"가
> 여기 적혀 있다** — 감각이 아니라 규칙이라는 것을 보여주는 것이 목적이다.

---

## 순서 — 반드시 이대로

**내용 → 구조 → 디자인.** 순서를 바꾸면 예쁜데 할 말이 없는 자료가 나온다.

### 1. 주제와 청중을 묻는다

- 무슨 주제로, 누구 앞에서, 몇 분 동안?
- 학교 수행평가면 과목·분량 조건도 확인한다.

### 2. 개요를 먼저 보여주고 확인받는다

슬라이드를 만들기 전에 **장 구성을 목록으로** 제시하고 사용자 확인을 받는다.

```
1. 표지
2. 왜 이 주제인가
3~5. 핵심 내용
6. 정리
7. 출처
```

- 기본 5~7장. 더 원하면 "장수가 늘면 발표 시간도 늘어요"라고 알린다.
- **한 장 = 한 메시지.** 두 가지를 말하고 싶으면 두 장으로 나눈다.

### 3. 원고를 쓴다

`.md` 원고를 만든다. 문법은 아래 「원고 문법」 참조.

### 4. 빌드한다

```bash
python3 decks/build-deck.py <원고>.md
```

없으면 `template.html`을 복사해 슬라이드 부분만 채운다.

### 5. 확인하고 다듬는다

"작품관 주소 뒤에 파일명을 붙여 열어보세요. 방향키로 넘어가요."
수정 요청을 반복해 완성한다.

## 원고 문법

| 쓰기 | 뜻 |
|---|---|
| `---` | 슬라이드 구분 |
| `<!-- class: cover -->` | 표지 |
| `<!-- class: chapter -->` | 간지 (큰 번호) |
| `# ## ###` | 제목 |
| `^ 텍스트` | 제목 위 작은 라벨 |
| `^^^` | 이 아래는 한 단계 뒤에 나타남 |
| `??? 텍스트` | 발표자 노트 (화면에 안 나옴, `S` 키) |
| 표·목록·코드·인용 | 마크다운 그대로 |

```markdown
<!-- class: cover -->
^ 2학년 3반 김OO
# 플라스틱은 <em>어디로 갈까</em>

우리가 버린 페트병의 3개월을 따라가 봤습니다.

---

## 왜 이 주제를 <b>골랐나</b>

^^^
- 급식실 분리수거함이 늘 넘쳐 있었습니다
- "제대로 버리면 재활용된다"는 말이 사실인지 궁금했습니다

??? 여기서 2분. 사진 한 장 띄우고 시작.
```

## 디자인 규칙 — 손대지 않는다

**색과 글꼴은 이미 정해져 있다.** 매번 새로 고르지 않는 것이 "일관되게 보이는" 이유다.

| 항목 | 값 | 이유 |
|---|---|---|
| 바탕 | 순검정 | 프로젝터에서 눈이 덜 피로하다 |
| 글자 | 흰색 계열 3단계 | 제목·본문·설명이 밝기로 구분된다 |
| 강조색 | 화면당 **한 가지** | 두 개면 어디를 볼지 모른다 |
| 글꼴 | 한 종류, 굵기만 다르게 | 글꼴을 섞으면 산만해진다 |
| 테두리 | 1px 얇은 선 | 그림자 대신. 화면이 무거워지지 않는다 |

바꾸고 싶다면 **CSS 변수만** 수정한다. 개별 요소에 색을 직접 쓰지 않는다.

### 한 장에 넣는 양

- 본문 **6줄 이하**. 넘으면 두 장으로 나눈다
- 표는 **5행 이하**. 넘으면 유인물로 뺀다
- 카드는 **3~4개**. 5개부터 글자가 안 읽힌다

### 넣지 않는 것

- 제목 앞 이모지
- 모든 것을 가운데 정렬
- 순서가 아닌데 붙이는 01 / 02 / 03 번호
- 슬라이드마다 다른 전환 효과
- 읽을 수 없는 크기의 글자 (프로젝터에서 확인할 것)

## 자주 쓰는 조각

**흐름 — 단계를 보여줄 때**

```html
<div class="flow">
  <span>수거</span><i>→</i><span>선별</span><i>→</i>
  <span class="hi">재활용</span><i>→</i><span>제품</span>
</div>
```

**숫자 — 크기를 각인시킬 때** (화면에 들어올 때 0부터 차오른다)

```html
<div class="grid c3">
  <div class="card"><div class="k">하루 배출량</div>
    <div class="v" data-count="1200" data-suffix="톤"></div></div>
</div>
```

**막대 — 둘을 비교할 때**

```html
<div class="bars">
  <div class="bar"><span class="t">2020년</span>
    <span class="track"><i style="--w:100%"></i></span><span class="n">100%</span></div>
  <div class="bar c2"><span class="t">2025년</span>
    <span class="track"><i style="--w:62%"></i></span><span class="n">62%</span></div>
</div>
```

## 마지막 장은 출처

참고한 자료를 적게 한다. 학교 제출물이면 **"AI 도구를 활용해 만들었다"는 표기**도 안내한다.

## 하지 않는 것

- 개요를 확인받기 전에 슬라이드부터 만들지 않는다
- 내용을 지어내지 않는다. 사실 확인이 필요하면 "이거 확인했어요?"라고 묻는다
- 색·글꼴을 임의로 새로 정하지 않는다
