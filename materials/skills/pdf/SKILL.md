# 스킬: PDF 로 바꾸기

학생이 만든 HTML 발표자료를 **PDF 로 제출·인쇄**해야 할 때 이 스킬을 따른다.

---

## 먼저 알아야 할 것 — 그냥 인쇄하면 1쪽만 나온다

발표자료 HTML 은 **지금 보는 장만 화면에 띄우고 나머지는 숨겨 두는** 구조다.
브라우저 인쇄를 그대로 쓰면 숨은 장은 인쇄되지 않는다.

실측 (2026-09-01): 7장짜리 자료 → **1쪽**. 우리 수업 엔진으로 만든 11장짜리도 → **1쪽**.

그래서 인쇄 직전에 **모든 장을 펼치고 한 장마다 쪽을 끊는 CSS** 를 끼워 넣는다.
아래 도구가 그 일을 한다. 원본은 건드리지 않는다.

---

## 순서 — 반드시 이대로

### 1. 원본을 확인한다

```bash
ls *.html
```

### 2. 변환한다

```bash
python3 ~/.codex/skills/pdf/html2pdf.py <원본>.html <결과>.pdf
```

쪽수가 출력된다. **슬라이드 수와 다르면 경고가 함께 나온다.**

### 3. 확인한다

- 쪽수 = 원본 장수인가?
- 내려받아 열어서 **첫 쪽과 마지막 쪽**을 눈으로 본다
- 글자가 잘리지 않았는가? (잘렸으면 원본에서 글을 줄이고 다시 변환)

### 4. 제출본으로 다듬는다

고칠 것이 있으면 **원본 HTML 을 고치고 다시 변환한다.** PDF 를 직접 손대지 않는다.

---

## 결과물 규칙

| 항목 | 값 | 이유 |
|---|---|---|
| 쪽 크기 | 13.333 x 7.5 inch (16:9) | 화면 비율 그대로. 여백 없이 꽉 찬다 |
| 여백 | 0 | 슬라이드가 이미 여백을 갖고 있다 |
| 머리말·꼬리말 | 없음 | 날짜·주소가 찍히면 제출물이 지저분해진다 |
| 쪽 나눔 | 슬라이드 1장 = 1쪽 | |

---

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 1쪽만 나온다 | 슬라이드가 `class="slide"` 나 `<section>` 인지 확인. 다른 이름이면 도구의 인쇄 CSS 에 그 이름을 추가한다 |
| 쪽수는 맞는데 내용이 잘린다 | 원본 한 장에 글이 너무 많다. 두 장으로 나눈다 |
| 그림이 빠진다 | 그림 파일이 HTML 과 같은 폴더에 있는지 확인 |

## 하지 않는 것

- 원본 HTML 을 고쳐서 인쇄용으로 만들지 않는다 (도구가 임시 사본에 처리한다)
- 쪽수를 확인하지 않고 "완성했어요"라고 말하지 않는다
