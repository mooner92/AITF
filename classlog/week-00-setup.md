# Week 00 — 세팅 일지

## 2026-08-16 · 서버 실사 + 계획 수립

수업 서버로 쓸 기존 OCI 인스턴스를 실사하고 세팅 계획을 스펙(specs/)으로 정리했다.

**실사에서 배운 것 (계획이 3번 바뀐 이유):**

1. "인스턴스 리사이즈가 필요하다"고 알고 있었는데, 메타데이터를 조회해 보니 이미 무료 한도 최대 셰이프(4 OCPU/24GB)였다. → 추측 말고 `curl`로 메타데이터를 직접 확인할 것.
2. 루트 디스크가 96% 차 있어서 큰일 난 줄 알았는데, `lsblk`를 보니 부트 볼륨 200G 중 155G가 파티션 밖에 미할당 상태였다. → 콘솔 작업 없이 서버 안에서 확장 가능. "디스크 부족"과 "볼륨 부족"은 다른 문제다.
3. 이 서버는 전용이 아니라 기존 서비스가 함께 도는 공용 서버다. → 두 가지 설계 변경: ① 127.0.0.1 바인딩만으로는 로컬 계정(학생)을 못 막으므로 내부 서비스에 인증 추가 ② 부하 테스트 통과 기준에 "기존 서비스 무영향" 추가.

**오늘 한 것:** 저장소 개설, 공개/비공개 2-존 정책(SECURITY.md) + pre-commit 시크릿 스캔 훅, specs 000~100 작성, 운영 스크립트 공개 버전 작성.

**다음:** 부트 볼륨 백업(운영자) → 디스크 확장 → P1 잔여 → P2 접속 경로.
