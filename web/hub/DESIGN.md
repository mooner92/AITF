# 관제탑 디자인 룰 — xAI 디자인 언어 기반

> 정본. 관제탑(그리고 앞으로 만드는 **운영 도구 웹**)은 이 룰을 따른다.
> 배포물·발표자료는 기존 [`docs/design-spec.md`](../../docs/design-spec.md)를 따른다 — 두 체계는 섞지 않는다.
> 출처: xAI 디자인 분석 스펙(2026-08-24 수령). 원칙 = "engineered restraint" —
> 근흑 캔버스 하나, 흰 아웃라인 필, 웨이트 400 단일, 그림자 없음.

## 1. 토큰

### 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `--canvas` | `#0a0a0a` | 유일한 페이지 배경. 라이트 모드 없음 |
| `--canvas-soft` | `#1a1c20` | 인풋·호버·중첩 표면 |
| `--canvas-card` | `#191919` | 카드 배경 |
| `--hairline` | `#212327` | 1px 경계선 — 그림자 대신 이것이 고도(elevation)의 전부 |
| `--ink` | `#ffffff` | 제목·기본 텍스트·아웃라인 필 |
| `--body` | `#dadbdf` | 보조 본문 |
| `--mute` | `#7d8187` | 캡션·비활성 |
| `--accent-sunset` | `#ff7a17` | 차트 1 · **경고 시맨틱 겸용** |
| `--accent-breeze` | `#a0c3ec` | 차트 2 |
| `--accent-dusk` | `#7c3aed` | 차트 3 |
| `--accent-twilight` | `#c4b5fd` | 차트 4 |

**시맨틱 예외** (xAI 원본에는 없으나 운영 도구라 필요 — 이 두 개 외 추가 금지):

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ok` | `--ink` (흰 점) | 정상 — "정상은 색이 아니라 침묵"이 이 언어의 태도 |
| `--fail` | `#ff453a` | 실패·죽은 서비스. 경고는 `--accent-sunset` 재사용 |

### 타이포그래피

**본문 폰트는 Paperlogy(웨이트 400)** — 한글 음절 전체를 서브셋해 임베드한다(woff2 135KB).
xAI 원본은 mono 캡션 페이스를 아이브로우·배지 전반에 쓰지만, **우리는 mono 를 코드·경로에만**
쓴다(가독성 판단, 2026-08-24). 아이브로우의 "기술 문서" 성격은 mono 가 아니라
**대문자 + 넓은 트래킹**으로 낸다.

| 역할 | 폰트 | 크기/행간 | 자간 | 규칙 |
|---|---|---|---|---|
| display-lg | Paperlogy | 44/1.05 | **-.03em** | 페이지 제목 |
| body | 〃 | 15/1.6 | 0 | 기본 본문 |
| body-sm | 〃 | 14/1.6 | 0 | 표·행 |
| eyebrow | 〃 | 11/16 | **+.16em** | **대문자 아이브로우** (mono 아님) |
| badge | 〃 | 12 | +.06em | 배지·상태 |
| code | ui-monospace | 13 | 0 | **경로·명령 전용** |

- **웨이트 400 단일. 볼드 금지** — 강조는 크기·자간·mono 전환으로만
- 디스플레이는 음수 자간(정밀함), 아이브로우는 양수 자간 — 이 대비가 목소리다
- 폰트는 **base64 woff2 로 임베드**한다 — 외부 요청 0 원칙을 지키면서 글꼴을 보장

### 형태·간격

- 반경 2종뿐: 카드 `8px` / **모든 인터랙티브 요소는 필 `9999px`**
- 간격은 4px 배수: 4·8·12·16·24·32·48·64
- **그림자 전면 금지.** hairline 1px 이 전부

## 2. 컴포넌트 (shadcn 구조를 정적 구현)

[shadcn/ui](https://ui.shadcn.com/) 컴포넌트의 **구조와 문법**을 따르되, 이 페이지는
외부 요청 0의 단일 정적 HTML이므로 React 빌드 없이 같은 형태를 CSS/vanilla JS로 구현한다.
(docs/design-spec §5 의 shadcn 차트 팔레트 채택과 같은 계보의 결정)

| shadcn 컴포넌트 | 정적 구현 규칙 |
|---|---|
| **Navigation Menu** | 상단 고정 바(캔버스 배경·hairline 하단). 항목은 필 — 활성 = 흰 채움+검정 글자(polarity flip), 비활성 = 텍스트만. 해시 라우팅 탭 |
| **Card** | `--canvas-card` + hairline + 8px + 22px 패딩. CardHeader = 대문자 아이브로우 |
| **Table** | 헤더 = 대문자 트래킹 `--mute`, 행 경계 hairline, 숫자 열 `tabular-nums` 우측 정렬. 넓으면 `overflow-x:auto` 로 감싼다 |
| **Badge** | 필 형태 + hairline. 상태 행은 점(dot) 선행 |
| **Progress** | 높이 6px, 트랙 `--canvas-soft`, 채움 `--ink`. 12주 진행률은 12분절 세그먼트 변형 |
| **Chart (bar)** | 수평 바를 **`라벨 \| 트랙 \| 값` 3열 그리드**로. 값을 절대 위치로 띄우면 최댓값에서 카드 밖으로 넘친다 |
| **Button** | 아웃라인 필(기본). 채움 필은 화면당 최대 1개 |
| **Tabs** | Navigation Menu 로 통합 — 별도 탭 UI 안 만듦 |

## 3. Do / Don't

**Do**
- 캔버스는 `#0a0a0a` 하나. 상태·데이터가 유일한 색 사용처
- 아이브로우는 대문자 + 넓은 트래킹 — 모든 카드·섹션 제목 위에
- 인터랙티브 = 필. 예외 없음

**Don't**
- 긴 코드·경로를 가로 스크롤 상자로 보여주지 않는다 — 설명 + 복사 버튼으로 대체
- 라이트 모드 만들지 않는다 (운영 도구는 다크 단일 — 명시적 선택)
- 볼드 금지, 그림자 금지, 그라데이션 히어로 금지
- 시맨틱 색을 §1 표 밖으로 늘리지 않는다 (초록 "성공" 추가 금지 — 정상은 흰 점)
- 차트 색을 시맨틱으로 쓰지 않는다 (sunset 은 차트 1이면서 경고지만, 같은 화면에서 두 의미가 충돌하면 차트가 양보)
