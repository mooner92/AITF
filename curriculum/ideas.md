## 2026-08-31 · "채팅 vs 폴더+AGENTS.md" — 지식 관리 방식의 차이를 실물로 보여주기

**아이디어**: 학생 각자의 실생활 주제(학교 수업, 동아리, 시험 준비 등)로
`~/school` 같은 폴더를 만들고 그 안에 AGENTS.md(지시서)와 자료 파일을 두고
에이전트와 작업하게 한다 — "채팅창에서 매번 다시 설명하는 방식"과 정면 비교.

**보여주려는 대비** (객관적으로, 실연으로):

| | 채팅창에서만 | 폴더 + AGENTS.md |
|---|---|---|
| 맥락 | 대화 끝나면 증발 — 매번 처음부터 설명 | 폴더에 남음 — 열 때마다 이어짐 |
| 규칙 | 매번 다시 말해야 함 ("존댓말로 써줘"×N) | AGENTS.md 에 한 번 적으면 계속 적용 |
| 산출물 | 복사해서 어딘가 붙여넣어야 함 | 파일로 바로 생김·수정됨 |
| 축적 | 지난 대화를 못 찾음 | 위키처럼 유기적으로 쌓임 — 나중에 검색·연결 |
| 이관 | 다른 도구로 못 가져감 | 폴더째 들고 어디든 감 |

**우리 수업과의 연결 고리**:
- 1주차에 이미 겪은 "복사·저장·새로고침 바퀴"의 확장판 — 채팅의 불편함을
  한 번 더, 이번엔 **지식 관리** 차원에서 체감시킨다
- 4주차(AGENTS.md 직접 수정)의 실전 응용 사례로 적합 — "내 규칙이 든 에이전트"를
  수업 밖 자기 삶에 쓰는 첫 사례
- 7주차 LLM 위키 공개와 같은 원리 — "서버가 우리 수업을 폴더+md 로 관리해 온 것처럼,
  너도 네 학교 생활을 그렇게 관리할 수 있다"로 잇는다
- 학생이 수업 밖으로 가져가는 첫 개인 프로젝트가 될 수 있음 (portable — 폴더째 소유)

**실연 구성 초안** (자료 만들 때 참고):
1. 같은 과제를 두 방식으로 시연 — ① 채팅창: 맥락 설명부터 다시 ② `~/school` 폴더:
   `codex` 열자마자 AGENTS.md 를 읽고 바로 이어서 작업
2. 일주일 뒤를 시뮬레이션 — 채팅은 히스토리 스크롤 지옥, 폴더는 `ls` 한 번
3. 학생 각자 자기 주제로 폴더 하나 만들기 (AGENTS.md 는 4주차에 배운 4요소로)

**주의**: 학교 과제 대필로 흐르지 않게 — "정리·계획·복습 도우미" 프레임으로.
AGENTS.md 에 "답을 대신 쓰지 않는다" 규칙을 넣는 것 자체가 좋은 실습이 된다.
