## 만드는 것: "내 최애 전문가 AI"

자기가 제일 잘 아는 주제(게임 공략, 아이돌, 웹툰, 축구팀, 요리…)의 자료를 모아,
**그걸 읽고 답하는 나만의 AI**를 AI 코딩 에이전트로 직접 만든다.

> 일반 AI는 "우리 학교 급식 뭐야?"를 모른다. 내 AI는 안다.
> **"AI가 모르는 걸 아는 AI를 내가 만들었다"** — 이게 12주의 목표.

뼈대는 전원 동일, 데이터만 각자 다르다. 그래서 서로 비교가 되고, 서로 도울 수 있다.

## 12주 흐름 (산출물 기준)

| 주차 | 이번 주에 만드는 것 |
|---|---|
| 1 | AI가 만든 나만의 터미널 명함 |
| 2 | 내 주제 폴더 + 첫 자료 문서 |
| 3 | 내 자료를 읽고 답하는 첫 Q&A 성공 |
| 4 | 내 사용 데이터 리포트 (읽는 법 포함) |
| 5 | 같은 일을 더 잘하는 방법 — 비교 숫자 ★전환점 |
| 6 | 강화된 내 AI + 첫 커밋 (git 시작) |
| 7 | 기능 확장 + 도구 속 들여다보기 |
| 8 | 완성도 올리기 (버퍼 주간) |
| 9 | 완성작 + **AI 아레나** (서로의 AI에 도전) |
| 10 | ★★ 비밀 공개 주간 (스포일러 금지) |
| 11 | 개선과 확장 (반별로 다른 길) |
| 12 | **2차 스프린트** — 숫자로 증명 + 수료 |

## 매주 반복되는 것

- **프롬프트 골프** (첫 10분): 전원 같은 미니 목표를 "가장 적은 토큰"으로 달성하기 — 주간 리그
- 매주 결과물 커밋 (6주차부터) — 12주 뒤 내 성장 히스토리가 남는다
- 결석해도 OK: 작업이 서버에 남아 있어 다음 주에 이어서, "따라잡기 카드"로 핵심 3줄 보충

## 중등반 / 고등반 차이

같은 프로젝트, 같은 뼈대. 중등반은 게임·미션 중심으로, 고등반은 더 깊게(직접 만들기·성능 개선·보안 실습·포트폴리오 정리) 간다.
