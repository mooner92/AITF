① 계정과 비용

AI 서비스 계정 (필수)

요청: OpenAI Platform에 계정을 만들고 결제수단을 등록해 주세요. 학원 명의로 되어 있는지도 함께 확인 부탁드립니다.

  • 학생 수만큼 개별 API 키를 발급해 계정별로 사용량을 분리해 두겠습니다.
  • 키마다 사용 상한(hard cap)을 걸어두면 예산 초과가 구조적으로 불가능해집니다.

도메인 · 서버 해결됨

수업용 서버와 접속 주소는 제가 가진 자원으로 이미 구축 완료되었습니다. 학원에서 따로 부담하실 비용은 없습니다. 리눅스 서버, 학생별 계정, 작품 전시용 웹 공간, 내부 버전관리 서버, 사용량 모니터링까지 모두 포함되어 있습니다.

② 네트워크

고정 IP 확인

요청: 학원 네트워크에서 아래 주소에 한번 접속해 표시되는 IP 주소를 알려주시면 됩니다. 가능하면 다른 날 두 번 확인해 값이 같은지 봐주시면 가장 좋습니다.

https://ifconfig.me

또는 인터넷 회선 계약서에 "고정 IP" 항목이 있는지 확인해 주셔도 됩니다.

왜 필요한가

학원에서 접속할 때 로그인 화면 없이 바로 수업 화면이 뜨게 하기 위해서입니다. 12명이 수업 시작과 동시에 로그인하다 보면 첫 10분이 그냥 지나갑니다.

확인 결과학생 접속 방식
고정 IP학원에서는 로그인 없이 즉시 접속
유동 IP매 수업 전에 제가 IP를 갱신하거나 학생별 인증 절차를 추가

없어도 수업은 가능합니다. 다만 매 수업 시작이 번거로워집니다.

방화벽 · 접속 제한 확인

요청: 학원 네트워크에서 아래가 차단되어 있는지 확인 부탁드립니다.

  • 일반 웹사이트(HTTPS) 접속 — 특히 처음 보는 도메인 차단 정책이 있는지
  • 브라우저에서 터미널 화면(웹소켓 통신)이 동작하는지
확인 방법

개강 전에 제가 주소를 보내드릴 테니 학원 노트북 한 대로 열어봐 주시면 됩니다. 5분이면 끝납니다. 이 확인 하나로 개강일 사고를 미리 막을 수 있습니다.

실습 노트북

요청: 학생 수만큼 노트북을 확보해 주시고 최신 브라우저(Chrome / Edge / Safari)인지 확인해 주시면 됩니다.

  • 따로 설치하실 프로그램은 없습니다. 브라우저 하나면 됩니다.
  • 사양은 상관없습니다. 실제 작업은 서버에서 돌아가니 오래된 노트북도 괜찮습니다.

학교 과제 활용 방침 (권장)

5주차에 만드는 발표 슬라이드는 실제 학교 수행평가에 쓸 수 있는 수준입니다. 학교마다 AI 활용 규정이 다르니 학원 차원의 지도 방침을 미리 정해두시면 좋겠습니다.

권장 방침

"AI 도구를 활용해 만들었음을 표기하도록 지도" — 수업 중에도 출처·활용 표기를 가르칩니다. 이 방침이 있으면 나중에 민원 소지를 걱정하지 않으셔도 됩니다.

진도·범위 조정 (미리 양해 요청)

이 분야는 몇 달이면 판이 바뀝니다. 개강 시점에 12주를 못박아두면 후반부에는 이미 낡은 것을 가르치게 되어, 주차별 목표는 고정하되 그 목표를 달성하는 재료만 그때의 최신 도구로 교체하는 방식으로 운영하려고 합니다.

바뀌지 않는 것

12주라는 기간, 주차별로 무엇을 완성하는가, 수료 시점의 결과물(작품 12개와 작품관), 그리고 학생이 익히는 개발 역량은 그대로입니다. 바뀌는 것은 무엇으로 만드느냐뿐입니다.

교체는 직전 주 수업 전까지 정하고 서버에 미리 설치·검증한 뒤에 들어갑니다. 검증하지 않은 도구를 수업 중에 즉석으로 쓰는 일은 없습니다. 별도 승인 절차가 필요하다고 보시면 말씀해 주세요. 그게 아니면 교체 이력을 수업 기록에 남겨 공유하겠습니다.
