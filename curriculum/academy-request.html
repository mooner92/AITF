① 계정과 비용

AI 서비스 계정 (필수)

요청: OpenAI Platform 계정 개설 + 결제수단 등록 + 학원 명의 확인

  • 학생 수만큼 개별 API 키를 발급해 계정별로 사용량을 분리합니다.
  • 키마다 사용 상한(hard cap)을 걸어 예산 초과가 구조적으로 불가능하게 만듭니다.

예상 비용 (12명 × 12주 × 2시간 기준)

항목금액

추정 폭이 넓은 이유

학생마다 사용 강도가 다르기 때문입니다. 상한이 있어 총액은 어떤 경우에도 학생 수 × 상한을 넘지 않습니다. 개강 후 2주간 실측하면 상한을 조정할 수 있습니다.

도메인 · 서버 해결됨

수업용 서버와 접속 주소는 강사가 보유한 자원으로 이미 구축 완료되었습니다. 학원의 추가 비용이 없습니다 — 리눅스 서버, 학생별 계정, 작품 전시용 웹 공간, 내부 버전관리 서버, 사용량 모니터링이 모두 포함됩니다.

② 네트워크

고정 IP 확인

요청: 학원 네트워크에서 아래 주소에 접속해 표시되는 IP 주소를 알려주세요. 가능하면 다른 날 두 번 확인해 값이 같은지 봐주시면 가장 좋습니다.

https://ifconfig.me

또는 인터넷 회선 계약서에 "고정 IP" 항목이 있는지 확인해 주셔도 됩니다.

왜 필요한가

학원에서 접속할 때 로그인 화면 없이 바로 수업 화면이 뜨게 하기 위함입니다. 12명이 수업 시작과 동시에 로그인 절차를 밟으면 첫 10분이 사라집니다.

확인 결과학생 접속 방식
고정 IP학원에서는 로그인 없이 즉시 접속
유동 IP매 수업 전 강사가 IP를 갱신하거나, 학생별 인증 절차를 추가

없어도 수업은 가능합니다. 다만 매 수업 시작이 번거로워집니다.

방화벽 · 접속 제한 확인

요청: 학원 네트워크에서 아래가 차단되어 있는지 확인 부탁드립니다.

  • 일반 웹사이트(HTTPS) 접속 — 특히 처음 보는 도메인 차단 정책이 있는지
  • 브라우저에서 터미널 화면(웹소켓 통신)이 동작하는지
확인 방법

개강 전 강사가 주소를 드리면 학원 노트북 한 대로 열어보시면 됩니다. 5분이면 끝나고, 이 확인이 개강일 사고를 막습니다.

실습 노트북

요청: 학생 수만큼 노트북 확보 + 최신 브라우저(Chrome / Edge / Safari) 확인

  • 설치할 프로그램은 없습니다. 브라우저만 있으면 됩니다.
  • 사양 무관 — 실제 작업은 서버에서 돌아갑니다. 오래된 노트북도 괜찮습니다.

권장 방침

"AI 도구를 활용해 만들었음을 표기하도록 지도" — 수업 중에도 출처·활용 표기를 가르칩니다. 이 방침이 있으면 나중에 민원 소지가 없습니다.
