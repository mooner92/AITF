**요일·시간** · 매주 일요일 / 중등반 14:00–16:00 · 고등반 16:00–18:00

## 1. 과정 개요

### 무엇을 만드나

학생이 **자기가 가장 잘 아는 주제**(게임 공략, 아이돌, 웹툰, 축구팀, 요리 등)의 자료를 모아,
그 자료를 읽고 답하는 **나만의 전문가 AI**를 직접 만듭니다.

뼈대는 전원 동일하고 데이터만 각자 다릅니다. 그래서 서로 비교가 되고, 서로 도울 수 있습니다.

> 일반 AI는 "우리 학교 급식 뭐야?"를 모릅니다. 학생이 만든 AI는 압니다.
> **"AI가 모르는 걸 아는 AI를 내가 만들었다"** — 12주 뒤 학생이 갖게 될 문장입니다.

### 무엇을 배우나

| 영역 | 12주 뒤 할 수 있게 되는 것 |
|---|---|
| **AI 활용** | 원하는 결과를 얻는 지시문을 쓰고, 안 될 때 원인을 짚어 고칠 수 있다 |
| **비용 감각** | 자기가 쓴 자원을 숫자로 읽고, 같은 결과를 더 적게 써서 낼 수 있다 |
| **도구 이해** | AI 도구가 어떤 구조로 동작하는지 알고, 설정을 직접 바꿔 결과를 조정할 수 있다 |
| **협업 기초** | 터미널·버전 관리 등 실무에서 쓰는 도구를 실제 작업 흐름 안에서 사용한다 |

### 수업 방식

- **매주 결과물이 하나씩 나옵니다.** 개념 강의가 아니라 만드는 것이 그 주의 정체성입니다.
- **개념은 필요할 때 등장합니다.** 프로젝트가 그 개념을 요구하는 순간에만 설명합니다.
- **복습 강의가 없습니다.** 대신 매주 첫 10분에 짧은 미션으로 지난 감각을 되살립니다.
- **모든 작업이 서버에 저장됩니다.** 결석해도 다음 주에 이어서 할 수 있습니다.

경험이 아니라 **학교급**으로 나눕니다. 뼈대는 같고, 진행 톤과 심화 방향이 다릅니다.

| | 중등반 (14:00–16:00) | 고등반 (16:00–18:00) |
|---|---|---|
| **컨셉** | 시즌제 게임 — 주차마다 퀘스트, 시즌 포인트 누적 | 주니어 엔지니어 — 만들고, 측정하고, 개선한다 |
| **블록 길이** | 15~25분으로 짧게 끊어 전환 | 길게 이어가도 무방 |

| **심화 방향** | 공유용 화면 만들기 (가족·친구에게 자랑) | 검색 기술 심화 + 도구 설정 직접 수정 |
| **추가 산출물** | — | 프로젝트 요약 1장 (생활기록부·자기소개서 활용 가능) |

1주차에 10분 수준 진단을 하지만 **반 이동은 없습니다.** 진단 결과는 반 안에서 짝을 어떻게 묶을지
정하는 데만 씁니다.

## 3. 주차별 계획 — 중등반

매주 리듬: **첫 10분 미션 → 메인 블록 → 휴식 → 만들기 → 마무리·숙제**

| 주 | 주제 | 이번 주 결과물 | 숙제 (5~10분) |
|:--:|---|---|---|
| 1 | AI를 부려본다 | AI가 만든 나만의 터미널 명함 | 내가 잘 아는 것 3가지 적어오기 |
| 2 | AI에게는 손이 있다 | 내 주제 폴더 + 첫 자료 문서 | 내 AI가 답해줬으면 하는 질문 5개 |
| 3 | 내 AI가 처음 답하다 | 내 자료를 읽고 답하는 첫 성공 | 어려운 질문 3개 |
| 4 | 벽에 부딪힌다 | 내 사용 기록 리포트 (읽는 법 포함) | 가장 아까웠던 순간 1개와 이유 |
| 5 | ★ 짜증을 장비로 바꾼다 | 같은 일을 더 잘하는 방법 — 비교 숫자 | 도구 마켓에서 하나 찾아오기 |
| 6 | 장비를 골라 본격 구축 | 강화된 내 AI + 첫 저장 기록 | 추가하고 싶은 기능 계획 (그림 환영) |
| 7 | 속을 뜯어본다 | 기능 확장 + 도구 내부 읽어보기 | 없음 |
| 8 | 완성도 올리기 | 답변 품질 개선 (출처·정직함·말투) | 내 최고의 지시문 1개 골라오기 |
| 9 | ★ AI 아레나 | 완성작 + 서로의 AI에 질문 공방 | 휴식 |
| 10 | ★★ 비밀 공개 주간 | 9주치 내 데이터 분석 + 도구의 정체 | 낭비 지점 3개 찾기 |
| 11 | 개선하고 확장한다 | 개선 체크리스트 + 공유용 화면 | 체크리스트 완성 |
| 12 | ★ 숫자로 증명한다 | 1차 대비 절감률 + 시즌 시상 + 수료 | — |

**★ 표시 주차는 진행이 밀리면 안 되는 핵심 주차입니다.**

### 중등반 진행 특징

- **주간 미션 리그**: 매주 첫 10분, 전원 같은 목표를 가장 효율적으로 달성하기. 순위는 상위 3명과
  "이번 주 가장 많이 개선한 사람"만 공개합니다. **하위권은 노출하지 않습니다.**
- **시즌 포인트**: 미션 순위 + 좋은 질문·도움 채택 + 9주 아레나 성적을 누적해 12주차에 종합 시상합니다.
  중간에 동기가 끊기지 않게 하기 위한 장치입니다.
- 9주차 아레나는 일방향 발표가 아니라 **서로의 AI에 질문을 던지는 공방** 형식입니다.
  "모른다"고 정직하게 답하는 것도 성공으로 인정합니다.

## 4. 주차별 계획 — 고등반

| 주 | 주제 | 이번 주 결과물 | 숙제 (5~10분) |
|:--:|---|---|---|
| 1 | AI를 부려본다 | AI가 만든 나만의 터미널 명함 | 내가 잘 아는 것 3가지 적어오기 |
| 2 | AI에게는 손이 있다 | 내 주제 폴더 + 첫 자료 문서 | 내 AI가 답해줬으면 하는 질문 5개 |
| 3 | 내 AI가 처음 답하다 | 내 자료를 읽고 답하는 첫 성공 | 어려운 질문 3개 |
| 4 | 벽에 부딪힌다 | 사용 기록 리포트 + 비용 구조 분석 | 가장 아까웠던 순간 1개와 이유 |
| 5 | ★ 짜증을 장비로 바꾼다 | 도구 도입 전후 비교 측정 | 도구 마켓에서 하나 찾아오기 |
| 6 | 장비를 골라 본격 구축 | 강화된 내 AI + 첫 저장 기록<br>**+ 직접 만드는 도구 과제 시작** | 추가하고 싶은 기능 계획 |
| 7 | 속을 뜯어본다 | 기능 확장 + 자작 도구 중간 점검 | 없음 |
| 8 | 완성도 + **레드팀 데이** | 품질 개선 + 서로의 AI 약점 찾기 | 내 최고의 지시문 1개 골라오기 |
| 9 | ★ AI 아레나 | 완성작 + 서로의 AI에 질문 공방 | 휴식 |
| 10 | ★★ 비밀 공개 주간 | 데이터 분석 + 도구 구조 해설·토론 | 내가 바꾸고 싶은 설정 1개와 이유 |
| 11 | 개선하고 확장한다 | 검색 기술 심화 + **설정 직접 수정** | 개선 체크리스트 완성 |
| 12 | ★ 숫자로 증명한다 | 절감률 + 수정 효과 측정<br>**+ 프로젝트 요약 1장** | — |

### 고등반 진행 특징

- **자작 도구 과제 (6~7주)**: 마켓에서 고르는 데서 그치지 않고, 자기 프로젝트에 맞는 도구를
  직접 만들어 봅니다.
- **레드팀 데이 (8주)**: 옆 사람의 AI가 틀린 답을 하도록 유도하는 질문을 찾고, 당한 사람은 방어를
  개선합니다. AI 서비스의 취약점을 몸으로 이해하는 시간입니다.
  **시작 전 윤리 브리핑을 반드시 합니다** — "내 것을 튼튼하게 만들기 위한 공격이며, 서버나 타인
  계정에 대한 시도는 금지"임을 명시하고, 시스템적으로도 차단되어 있음을 알립니다.
- **설정 직접 수정 (11주)**: 도구가 어떻게 동작할지를 학생이 직접 조정하고, 그 효과를 12주차에
  숫자로 측정합니다.
- **프로젝트 요약 1장 (12주)**: 무엇을 만들었고 어떻게 개선했는지를 한 장으로 정리합니다.
  생활기록부·자기소개서에 활용할 수 있는 형태입니다.

|---|---|

| **개선 증명** | 1주차 대비 12주차 효율 개선률 (본인 대비 성장으로 측정) |

성장 측정은 **다른 학생과의 비교가 아니라 본인의 1차 기록 대비**로 합니다.

## 6. 운영 방침

### 숙제

**5~10분 · 종이나 휴대폰으로 가능 · 컴퓨터와 서버 접속 불필요.**
안 해와도 수업 진행에 지장이 없도록 설계했습니다.

> 학원은 학생에게 1순위가 아닙니다. 숙제를 전제로 설계하면 수업이 무너집니다.
> 숙제는 "다음 주 재료를 미리 생각해오는 것"이지 과제 부담이 아닙니다.

### 결석 대응

작업이 서버에 저장되어 있어 **다음 주에 그대로 이어서** 할 수 있습니다.
결석자에게는 놓친 주차의 핵심 3줄이 담긴 따라잡기 카드를 제공합니다.

### 소통

- 카카오 오픈채팅방을 운영하며, **응답 가능 시간대를 미리 공지**합니다.
- 질문은 공개로 답해 같은 질문의 반복을 줄입니다.

### 안전 관리

- 학생 계정은 서로의 파일에 접근할 수 없으며, 시스템 관리 권한이 없습니다.
- 학생별 자원 사용량에 상한이 걸려 있어 한 명의 실수가 다른 학생에게 영향을 주지 않습니다.
- 사용량은 강사가 실시간으로 확인하며, 외부 서비스 비용에는 계정별 상한이 설정됩니다.
- 매 수업 후 전원의 작업 상태를 백업합니다. 실수로 파일을 지워도 복구할 수 있습니다.

### 준비물

**없습니다.** 학원 노트북의 브라우저만 있으면 됩니다. 설치할 프로그램도, 만들 계정도 없습니다.
