## 1. 과정 개요

### 무엇을 만드나

학생이 **자기가 가장 잘 아는 주제**(게임 공략, 아이돌, 웹툰, 축구팀, 요리 등)의 자료를 모아,
그 자료를 읽고 답하는 **나만의 전문가 AI**를 직접 만듭니다.

뼈대는 전원 동일하고 데이터만 각자 다릅니다. 그래서 서로 비교가 되고, 서로 도울 수 있습니다.

> 일반 AI는 "우리 학교 급식 뭐야?"를 모릅니다. 학생이 만든 AI는 압니다.
> **"AI가 모르는 걸 아는 AI를 내가 만들었다"** — 12주 뒤 학생이 갖게 될 문장입니다.

### 12주 뒤 할 수 있게 되는 것

| 영역 | 구체적으로 |
|---|---|
| **AI 활용** | 원하는 결과를 얻는 지시문을 쓰고, 안 될 때 원인을 짚어 고칠 수 있다 |
| **비판적 사용** | AI 답변이 틀릴 수 있는 지점을 알고, 근거를 확인하는 습관이 있다 |
| **비용 감각** | 자기가 쓴 자원을 숫자로 읽고, 같은 결과를 더 적게 써서 낼 수 있다 |
| **협업 기초** | 터미널·버전 관리 등 실무 도구를 실제 작업 흐름 안에서 사용한다 |

### 수업 방식

- **매주 결과물이 하나씩 나옵니다.** 개념 강의가 아니라 만드는 것이 그 주의 정체성입니다.
- **개념은 필요할 때 등장합니다.** 프로젝트가 그 개념을 요구하는 순간에만 설명합니다.
- **모든 작업이 서버에 저장됩니다.** 결석해도 다음 주에 이어서 할 수 있습니다.
- **숙제가 없습니다.** 배우는 것은 전부 수업 시간 안에서 끝납니다.

## 2. 수업 참여 방법

### 학생이 하는 일: 주소 입력 → 아이디 입력. 끝.

```
① 학원 노트북에서 브라우저를 연다
        ↓
② 알려준 주소를 입력한다        ← 즐겨찾기 해두면 이후엔 클릭 한 번
        ↓
③ 터미널 화면이 바로 뜬다        ← 학원 네트워크에서는 로그인 화면 없음
        ↓
④ 본인 아이디와 비밀번호를 입력한다
        ↓
⑤ 지난주에 하던 작업이 그대로 있다  ← 저장·복원 과정 없음
```

**설치할 것이 없습니다.** 프로그램도, 확장 프로그램도, 회원가입도 없습니다.
학원 노트북이든 다른 컴퓨터든 브라우저만 있으면 같은 환경이 열립니다.

### 왜 이렇게 만들었나

| 흔한 문제 | 이 수업에서는 |
|---|---|
| 컴퓨터마다 설치 상태가 달라 첫 수업 1시간을 세팅에 씀 | 서버에 미리 다 준비되어 있어 첫날부터 바로 시작 |
| 집 컴퓨터에서 안 돌아감 | 브라우저만 있으면 어디서든 같은 환경 |
| 인터넷이 끊겨서 작업 날아감 | 작업이 서버에서 계속 돌아감. 다시 접속하면 그대로 |
| 실수로 파일을 지움 | 매주 백업. 복구 가능 |
| 계정을 잊어버림 | 아이디는 학원에서 발급·관리 (학생 이메일 수집 없음) |

### 집에서도 하고 싶은 학생

원하는 학생은 **집에서도 같은 화면에 접속**할 수 있습니다. 별도 설치 없이 브라우저만 있으면 됩니다.
다만 **선택 사항이며, 수업은 전적으로 수업 시간 안에서 완결됩니다.** 집에서 하지 않아도
진도에 아무 영향이 없습니다.

> 집 접속을 원하는 학생만 별도 인증을 등록합니다. 원하지 않는 학생은 등록하지 않아도 됩니다.

### 학생별 안전 장치

- 학생끼리 **서로의 파일에 접근할 수 없습니다.**
- 학생 계정에는 **시스템 관리 권한이 없습니다.** 서버 설정을 건드릴 수 없습니다.
- 계정별로 자원 사용량 상한이 걸려 있어 **한 명의 실수가 다른 학생에게 영향을 주지 않습니다.**
- AI 사용 비용에도 계정별 상한이 설정되어, 예상 밖의 비용이 발생하지 않습니다.
- 강사는 전체 사용 현황을 실시간으로 확인합니다.

### 중등반 진행 특징

**주간 미션 (매주 첫 10분)**
전원 같은 목표를 가장 효율적으로 달성하기. 공개하는 것은 **상위 3명**과 **"이번 주 가장 많이 개선한 사람"**
뿐입니다. 하위권은 노출하지 않습니다. 지난주 자기 기록을 넘는 것이 기본 목표입니다.

**시즌 포인트**
미션 기록 + 좋은 질문·도움 채택 + 9주 아레나 성적을 누적해 12주차에 종합 시상합니다.
중간에 동기가 끊기지 않게 하기 위한 장치입니다.

**9주 AI 아레나**
일방향 발표가 아니라 서로의 AI에 질문을 던지는 공방입니다.
**"모른다"고 정직하게 답하는 것도 성공으로 인정**합니다 — 8주차에 배운 것이 여기서 점수가 됩니다.

## 5. 주차별 계획 — 고등반

| 주 | 주제 | 이번 주 결과물 |

| 1 | AI를 부려본다 | AI가 만든 나만의 터미널 명함 |

| 3 | 내 AI가 처음 답하다 | 내 자료를 읽고 답하는 첫 성공 |
| 4 | 한계를 재본다 | 사용 기록 리포트 + 비용 구조 분석 |
| 5 | ★ 짜증을 장비로 바꾼다 | 도구 도입 전후 비교 측정 |
| 6 | 장비 장착, 기록 시작 | 강화된 내 AI + 첫 저장 기록<br>**+ 직접 만드는 도구 과제 시작** |
| 7 | **출처를 붙인다** | 근거를 제시하는 AI + 자작 도구 중간 점검 |
| 8 | **신뢰성 점검** | 틀린 답을 잡아내고 고친 기록 |
| 9 | ★ AI 아레나 | 완성작 + 서로의 AI에 질문 공방 |
| 10 | ★★ 비밀 공개 주간 | 데이터 분석 + 도구 구조 해설·토론 |
| 11 | 개선하고 확장한다 | 검색 기술 심화 + **설정 직접 수정** |
| 12 | ★ 숫자로 증명한다 | 개선률 + 수정 효과 측정<br>**+ 프로젝트 요약 1장** |

### 고등반 진행 특징

**자작 도구 과제 (6~7주)**
마켓에서 고르는 데서 그치지 않고, 자기 프로젝트에 맞는 도구를 직접 만들어 봅니다.

**신뢰성 점검 (8주)**
AI가 가장 위험한 순간은 **모르는 것을 아는 척 답할 때**입니다. 이 시간에 그것을 직접 찾아냅니다.

1. 짝과 AI를 교환하고, **자료에 답이 없는 질문 10개**를 만들어 던집니다.
2. AI가 "모른다"고 답하면 통과, 그럴듯한 거짓말을 하면 실패로 기록합니다.
3. 자기 AI로 돌아와 실패한 항목을 고치고, 다시 검사받습니다.
4. **점수 = 10문항 중 정직하게 답한 개수.** 개선 전후를 비교합니다.

정답이 명확하고(모르면 모른다고 해야 한다) 측정이 되며(10점 만점), 배운 것이 곧바로
9주 아레나 점수로 이어집니다.

**설정 직접 수정 (11주)**
도구가 어떻게 동작할지를 학생이 직접 조정하고, 그 효과를 12주차에 숫자로 측정합니다.

**프로젝트 요약 1장 (12주)**
무엇을 만들었고 어떻게 개선했는지를 한 장으로 정리합니다.
생활기록부·자기소개서에 활용할 수 있는 형태입니다.
