## 1. 수업 정체성

겉으로 보이는 결과물은 그림·발표자료·영상이지만, 매주 실제로 늘어나는 것은
**AI 도구를 다루는 깊이**입니다. 2주차에 도구의 구조를 알고, 4주차에 설정을 직접 고치고,
6주차에 자기 도구를 만듭니다. 이 세 지점을 지나면 학생은 AI를 "주어진 대로 쓰는 것"이
아니라 "고쳐 쓰는 것"으로 대하게 됩니다.

커리큘럼은 고정판이 아닙니다 — **주차별 목표는 고정, 재료는 그 달의 최신 도구로 교체**.
교체는 직전 주까지 결정하고 서버 검증 후 투입합니다.

## 2. 관통하는 세 갈래 (매주 반복)

| 갈래 | 시점 | 내용 |
|---|---|---|
| 내 기록 | 첫 5분 | 대시보드에서 지난주 자기 기록 확인. 순위표 없음 |
| 위키 | 10분 | 학생이 직접 기록 + 수업 후 자동 생성분 |
| 이번 주에 나온 것 | 마지막 5분 | 새 소식 1~2개. 숙제 대신 습관 |

## 3. 자동 위키 → Notion 발행

일요일 20시, 서버가 그날 활동(커밋·스킬·설정 변경·결과물·사용량)을 수집해
학생별·행위별 md를 만들고 그래프를 갱신한 뒤 **Notion 주간 페이지로 발행**하고
Slack `#위키`에 알립니다. 같은 스킬을 쓴 학생끼리 스킬 노드를 매개로 이어지고,
6주차 자작 스킬은 새 노드로 갈라져 나옵니다. **7주차 도입 15분에 처음 공개**합니다 —
"이걸 매주 AI가 자동으로 써왔다"가 그 주 주제(에이전틱)의 실물 예시가 됩니다.
계정 ID만 기록하고 반 내부만 열람합니다.
그래프는 **서버 웹페이지로 시각화**합니다 — 노드를 드래그하고 클릭하면 해당 문서로 이동.
7주차 공개 때 이 화면을 프로젝터에 띄우는 것이 공개 장면 그 자체입니다.

## 4. 수업 환경

| 구성 요소 | 설명 |
|---|---|
| 준비물 | 학생당 **구글 계정 1개** (개강 전 준비, 만 14세 미만 보호자 동의). 그 외 없음 |
| 접속 | 브라우저 → 전용 주소 → 바로 터미널 |
| 서버 | 학생별 독립 계정 (파일 격리, 관리 권한 없음) |
| 학생 페이지 | `~/project/public/` → `<주소>/pages/<계정>/` 즉시 공개 |
| 학생 웹서비스 | 9주차부터. 계정별 포트 100개 대역 + `mid01.<도메인>` 서브도메인 |
| 외부 접속 | 10주차 개방 — gmail 일회용 코드(24h 세션). 그 전에는 학원에서만 |
| 소통 | Slack (#질문·#작품·#모델비교·#위키). 학부모는 기존 학원 채널 |
| 모델 비교 봇 | `/compare` — 로컬 모델(qwen·gemma)과 GPT의 답·속도·비용 병기 |
| 위키·복습 | Gitea 위키(정본) → Notion 주간 발행 |
| 비용 통제 | 계정별 AI 상한, 이미지 주당 장수 제한 |
| 백업 | 매 수업 후 전원 스냅샷 |

공통 시간 골격(2시간): 내 기록 5분 → 도구 소개·시연 20분 → 실습 1 (35분) → 휴식 10분 →
실습 2 (35분) → 전시·커밋·위키 10분 → 이번 주에 나온 것 5분.

**중등·고등은 같은 내용으로 진행합니다** — 터미널 환경은 어느 쪽도 처음이라 출발선이
같습니다. 중등반은 실습 블록을 더 잘게 쪼개고, 빨리 끝낸 학생에게 심화 과제를 줍니다.

## 5. 주차별 상세

### 1주 — 터미널과 첫 대화

| | |
|---|---|
| **만들기 목표** | 내 프로필 카드 — 게임 전적·최애를 AI가 조사해 만든 터미널 카드 |
| **개발 역량** | 접속, tmux 3키(스크롤·중단·재입력), CLI 에이전트 첫 대화 |
| **사용 기술** | 브라우저 터미널, Codex CLI |

**진행**: 강사 소개 → 학생 이름 듣기(한 사람 15초) → 접속 5단계(25분 — 최대 변수) →
tmux 3키 → 세션 지속 시연 → **프로필 카드**: 자기 게임 전적(롤이면 op.gg)·최애를 AI가 웹
검색으로 조사해 터미널 카드로 — "AI가 인터넷에서 나를 찾아온다"가 첫 경험. 게임 안 하는
학생은 좋아하는 것 무엇이든 → 자연 연결: 방금은 검색해서 맞혔는데, 검색 없이 물으면?
(할루시네이션 시연 — 강사 이름 먼저, 학생은 희망자만) → 사용량 그래프 = 12주차 기준점 → 위키 예고.
**강사 준비**: 완성 예시, 치트시트 인쇄, 계정 카드(서버+Slack), gmail 미준비 학생용 예비 계정.

### 2주 — Codex는 챗봇이 아니다 + 모델을 고른다 ★기초 완결

| | |
|---|---|
| **만들기 목표** | 우리 반 모델 가이드 (위키 개설 겸 첫 문서) |
| **개발 역량** | CLI 에이전트의 구조 + 모델별 차이·비용 감각 |
| **사용 기술** | Codex CLI vs ChatGPT 웹 비교, Slack /compare 봇 데뷔 |

**진행**: ① 같은 요청을 둘에(30분) — 웹은 코드를 보여주고 CLI는 파일을 만든다 →
② 블라인드 테스트(40분) — /compare가 모델명을 가린 답 셋, 맞히기 3라운드(요약·창작·코드),
정답 공개 때 속도·비용 병기 → 태스크별 승자표: "일마다 적임자가 다르다"가 결론
(종합 승부면 큰 모델이 이기고 끝이라 태스크를 쪼갬) → ③ 정리(20분) — 위키 개설 +
"우리 반 모델 가이드" → **인터넷에 올리면 안 되는 것 5분**(실명·학교·연락처·얼굴 — 다음
주부터 실제 공개되기 전에 못박기) → 예고: "다음 주엔 학교 발표자료를 다시 만듭니다.
**최근 발표 주제 하나 기억해 오세요**(숙제 아님, 없으면 목록에서)."
**강사 준비**: ChatGPT 웹 계정, 비교 봇 가동(미승인 시 GPT 단독), 모델 실측 자료, 위키 초기 구조.

### 3주 — 첫 응용: 내 발표자료를 다시 만든다 ★실용 정점

| | |
|---|---|
| **만들기 목표** | 학교에서 실제 발표했던 주제의 HTML 발표자료 — 인터넷에 공개 |
| **개발 역량** | design.md로 결과물 다듬기, 내용 → 구조 → 디자인 순서 |
| **사용 기술** | Codex + design.md, 단체 디자인 세션(강사 Claude로 반 로고 제작) |

**진행**: ① 단체 디자인 세션(20분) — 프로젝터에 강사 Claude, 반 전체가 지시문을 만들어
우리 반 로고 제작. "지시문이 디자인을 바꾼다"를 전원이 목격 → ② 내 발표자료(60분) —
최근 학교 발표 주제를 개요(내용) 먼저 → 생성 → **design.md를 받아서 적용**("이 파일을 주면
디자인이 확 달라진다" — 왜 그런지는 다음 주에 뜯는다) → 다듬기 → ③ 공개(20분) —
public/에 넣는 순간 30초 안에 인터넷에. **학교 제출 시 AI 활용 표기** 지도 → 위키 기록.
이미 발표한 주제라 내용 고민이 없고, "학원에서 만든 걸 학교에서 썼다"가 나올 수 있는
가장 이른 지점 — 기초 직후 첫 응용이라 몰입이 가장 크다.
**강사 준비**: design.md 2~3종(스타일 다르게), 주제 제공 목록, 작품관 템플릿, 페이지 경로 확인.

### 4주 — 지시문과 설정, 그리고 되돌리기

| | |
|---|---|
| **만들기 목표** | 내 규칙이 들어간 에이전트 |
| **개발 역량** | 지시문 4요소, AGENTS.md 직접 수정, git 3동작 |
| **사용 기술** | AGENTS.md, git add/commit/push |

**진행**: **지난주 design.md를 뜯는다** — "디자인을 확 바꿨던 그 파일, 열어 보면 그냥 한국어
지시문이다" → "그럼 AI 자체에도 이런 파일이?" → AGENTS.md 공개·한 줄 수정 → 4요소 →
**하네스 추리 게임**:
짝의 AGENTS.md에 몰래 규칙 심기("답 끝에 냥", "숫자는 한글로") → 자리 바꿔 대화만으로 규칙
추리 — 웃기고, 그 속에서 "보이지 않는 지시서가 답을 조종한다"가 몸에 박힌다 →
일부러 망가뜨리기 → git으로 되돌리기(설정을 망칠 수 있어야 되돌리기가 절실) →
"방금 만진 게 **하네스**다" 원리 정리 → 예고: 다음 주엔 지시서를 통째로 갈아끼우는 물건(스킬).
**강사 준비**: 수정 후보 줄 목록(중등용), git 비유 슬라이드.

### 5주 — 남의 스킬을 갖다 쓴다 ★실용 정점

| | |
|---|---|
| **만들기 목표** | 포스터/이미지 + 발표 슬라이드 (학교 수행평가 수준) |
| **개발 역량** | 스킬 = 텍스트 파일, 마켓 탐색·설치, 마크다운 |

**진행**: 도입 — **3주차와의 대결**: design.md 들고 손으로 30분 걸린 발표자료를 슬라이드

**well-made 하네스 해부**: oh-my-codex 계열을 GitHub에서 clone, md를 직접 열어 —

이미지 생성 스킬(주당 장수 제한) — 포스터·삽화 → **스킬은 어디서 찾나**: GeekNews ·
Claude Skill Market · GitHub — 이 시점부터 자발적 탐색 시작, 수업 템포 가속 → 전시 → 위키 평가.
**강사 준비**: 스킬 설치·테스트, 장당 비용 실측 → 상한, 마켓 접근 확인,
**해부용 하네스 사전 분석 필수**(발동 조건·지시 구조·모델 전환 지점).

### 6주 — 나만의 스킬 만들기 ★불가침

| | |
|---|---|

| **개발 역량** | SKILL.md 작성 + 봇 연결 + MCP 개념 |
| **사용 기술** | SKILL.md, 상호 교환 검증 |

**진행**: "내가 매번 똑같이 시키는 게 뭐지?" → SKILL.md 정리 → 그 스킬을 **Slack 봇에
꽂는다**: 버스 도착(공공데이터포털)·급식·날씨 옷차림 등, 트리거 → 데이터 → 내 스킬(AI 가공) →
알림 4단 → **워크스페이스에 실제 추가** → 서로의 봇 구경 → **MCP 첫 등장**: "도구를 AI에
꽂는 표준 규격" — 개념만, 실사용은 다음 주. 스킬만 만들면 테스트가 루즈해지는데, 봇에 꽂으면
결과가 Slack 알림으로 즉시 떠서 테스트가 곧 재미다. 완성 기준: 첫 알림이 채널에 뜨면 성공 →
위키에 스킬 문서(그래프의 새 노드).
**강사 준비**: **봇 뼈대(웹훅)는 강사가 미리** — 학생은 스킬 로직만. 공공데이터포털 공용 키
사전 발급(하루쯤 걸림), Gemini 키 발급 절차, 소재 카드 3종.

### 7주 — 도구를 쓰는 AI ★위키 공개

| | |
|---|---|
| **만들기 목표** | 웹에서 모은 자료를 정리한 페이지 |
| **개발 역량** | 에이전틱 — AI가 도구를 써서 일한다, API 키 관리, 승인 경계 |
| **사용 기술** | Playwright + **Playwright MCP** — 브라우저 조작·스크린샷·GIF |

**진행**: 도입 15분 — 6주 쌓인 자동 위키를 **그래프 시각화 화면으로 공개** + "이걸 매주 AI가
써왔다" → 그 자동화가 오늘 주제 → 지난주 개념으로 배운 MCP를 **실제로 꽂는다: Playwright
MCP** — AI가 브라우저를 열고 조작하고 **스크린샷으로 증거를 남긴다** → 각자 과제: 사이트
하나를 조사해 스크린샷과 함께 정리 페이지 → 위험 명령 승인 토론.
**9주 웹 프로젝트의 예열**: 프로젝트에서 Playwright 테스트·스크린샷·GIF 설명서가 완성
요건이다 — 이 주에 손에 익혀 스스로 떠올려 쓰게 하는 것이 목표.
**강사 준비**: Playwright 6명 부하 실측, **Playwright MCP 사전 설치·검증**, 금지 사이트 목록,
위키 그래프 화면.

(봇 기능 추가 / 스킬 개선 / MCP 새 도구 / ffmpeg 영상화) → 공유 링크.
**진행 · 후반 50분 — 프로젝트 프리플라이트**: ① **내 서버 시운전** — MY-SERVER.md의 내
포트에 hello 페이지를 띄우고 `mid01.<도메인>` 주소로 열어본다(9주에 인프라로 시간을 잃지
않기 위해) ② **Playwright 리허설** — 방금 띄운 페이지 스크린샷 1장 ③ **아이디어 카드
3장** — 만들고 싶은 웹 프로젝트를 1인 3개 한 줄씩. 9주는 이 카드를 꺼내는 것으로 시작 →
마지막 15분: **AI 영상 걸어두고 하교**(8~10초 클립, 결과는 9주 공개 — 위임의 예고편).
**강사 준비**: **포트 배정·MY-SERVER.md를 이 주 전에 배포**(alloc-ports.sh --deploy),
오프라인 안내 페이지, 아이디어 카드 양식, AI 영상 생성 큐.
