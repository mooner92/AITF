# 학원 요청 사항 — AI 특강 개설 준비

> 개강 전까지 학원 측 협조가 필요한 항목입니다. **① 계정·비용**, **② 네트워크**,
> **③ 학생 정보**, **④ 운영 확인**, **⑤ 강사가 준비 중인 것** 순서입니다.
> 각 항목의 **왜 필요한가**와 **없으면 무엇이 막히는가**를 함께 적었습니다.

---

## ⚡ 가장 급한 3가지

| 순위 | 항목 | 없으면 막히는 것 | 마감 |
|:--:|---|---|---|
| 1 | **AI 서비스 계정 + 결제수단** | 수업의 모든 실습. 사전 검증도 불가 | 개강 3주 전 |
| 2 | **학원 고정 IP 확인** | 학생 접속 방식 결정 (설계 분기) | 개강 3주 전 |
| 3 | **학생 명단** | 계정·저장소 일괄 생성 | 개강 1주 전 |

## ① 계정과 비용

### 1-1. AI 서비스 계정 (필수)

**요청**: OpenAI Platform 계정 개설 + 결제수단 등록 + 학원 명의 확인

- 학생 수만큼 **개별 API 키**를 발급해 계정별로 사용량을 분리합니다.
- 키마다 **사용 상한(hard cap)**을 걸어 예산 초과가 구조적으로 불가능하게 만듭니다.

**예상 비용** (12명 × 12주 × 2시간 기준)

| 항목 | 금액 |
|---|---|
| 12주 전체 예상 | **약 $100~250** (13만~33만 원) |
| 학생 1인당 | 약 $8~20 |
| 권장 계정별 상한 | **$30** (예상의 1.5~3배 여유) |
| 최악의 경우 총액 | $360 (전원이 상한까지 사용 시) |

> 추정 폭이 넓은 이유는 학생의 사용 강도 차이입니다. 상한이 있어 **총액은 어떤 경우에도
> 학생 수 × 상한을 넘지 않습니다.** 개강 후 2주 실측하면 상한을 조정할 수 있습니다.

**없으면**: 실습이 전혀 불가능합니다. 사전 리허설·검증도 막혀 개강 리스크가 커집니다.

### 1-2. 도메인·서버 (해결됨 — 참고용)

수업용 서버와 접속 주소는 **강사가 보유한 자원으로 이미 구축 완료**되었습니다.
학원의 추가 비용이 없습니다.

- 리눅스 서버, 학생별 계정, 작품 전시용 웹 공간, 내부 버전관리 서버, 사용량 모니터링

## ② 네트워크

### 2-1. 학원 고정 IP 확인 (필수)

**요청**: 학원 네트워크에서 아래 주소에 접속해 **표시되는 IP 주소**를 알려주세요.
가능하면 **다른 날 두 번** 확인해 값이 같은지 봐주시면 가장 좋습니다.

```
https://ifconfig.me
```

또는 인터넷 회선 계약서에 "고정 IP" 항목이 있는지 확인해 주셔도 됩니다.

**왜 필요한가**: 학원에서 접속할 때 **로그인 화면 없이 바로 수업 화면이 뜨게** 하기 위함입니다.
12명이 수업 시작과 동시에 로그인 절차를 밟으면 첫 10분이 사라집니다.

| 결과 | 학생 접속 방식 |
|---|---|
| **고정 IP** | 학원에서는 로그인 없이 즉시 접속 ✅ |
| **유동 IP** | 매 수업 전 강사가 IP를 갱신하거나, 학생별 인증 절차 추가 |

**없으면**: 수업이 불가능하진 않지만 매 수업 시작이 번거로워집니다.

### 2-2. 방화벽·접속 제한 확인

**요청**: 학원 네트워크에서 아래가 차단되어 있는지 확인 부탁드립니다.

- 일반 웹사이트(HTTPS) 접속 — 특히 **처음 보는 도메인** 차단 정책이 있는지
- 브라우저에서 터미널 화면(웹소켓 통신)이 동작하는지

**확인 방법**: 개강 전 강사가 주소를 드리면, 학원 노트북 한 대로 열어보시면 됩니다.
**5분이면 끝나고, 이 확인이 개강일 사고를 막습니다.**

### 2-3. 실습 노트북

**요청**: 학생 수만큼 노트북 확보 + 최신 브라우저(Chrome/Edge/Safari) 설치 확인

- **설치할 프로그램은 없습니다.** 브라우저만 있으면 됩니다.
- 사양 무관 — 실제 작업은 서버에서 돌아갑니다. 오래된 노트북도 괜찮습니다.

## ③ 학생 정보

### 3-1. 명단 (필수)

**요청**: 개강 1주 전까지 아래 형식으로 주세요.

| 이름 | 학교급 | 반 |
|---|---|---|
| 홍길동 | 중등 | 중등반 |
| 김철수 | 고등 | 고등반 |

- **학생 이메일·전화번호는 필요 없습니다.** 계정은 학원 명의로 발급·관리합니다.
- 이름은 계정 ID 매핑용이며, 계정 ID는 `mid01`, `high01` 형식으로 별도 생성합니다.

**없으면**: 계정·저장소·작품관을 만들 수 없어 첫 수업이 세팅으로 소모됩니다.

### 3-2. 확정 인원

**요청**: 반별 최종 인원

현재 계획은 **반당 6명 내외** 기준입니다. 인원이 늘면 아래가 함께 조정됩니다.

- 서버 자원 배분 (1인당 메모리 상한)
- AI 사용 예산 총액
- 수업 중 개별 지도 가능 시간

> **반당 8명을 넘으면** 강사 1인 기준 개별 지도가 어려워집니다. 그 이상이면
> 진행 방식(짝 활동 비중 확대 등) 조정을 함께 논의하고 싶습니다.

## ④ 운영 확인 사항

### 4-1. 결정이 필요한 것

| 항목 | 선택지 | 강사 의견 |
|---|---|---|
| **작품 공개 범위** | ⓐ 링크 아는 사람만 ⓑ 학원 홍보 활용 | ⓐ 기본. ⓑ면 **학부모 동의서** 필요 |
| **수료 기준** | 출석률 기준, 수료증 발급 여부 | 출석 70% 이상 권장 |
| **개인 기기 사용** | 후반부(8주~) 휴대폰으로 진행상황 확인 — **선택 사항** | 원하는 학생만. **동의 절차 필요** |
| **결석 보강** | 별도 보강 여부 | 8주차가 보충 시간을 겸하도록 설계됨 |

### 4-2. 학교 과제 활용 방침 (권장)

5주차에 만드는 **발표 슬라이드는 실제 학교 수행평가에 쓸 수 있는 수준**입니다.
학교마다 AI 활용 규정이 달라, 학원 차원의 지도 방침을 미리 정해두시길 권합니다.

**권장**: "AI 도구를 활용해 만들었음을 표기하도록 지도" — 수업 중에도 출처·활용 표기를
가르칩니다. 이 방침이 있으면 나중에 민원 소지가 없습니다.

### 4-3. 소통 채널

**요청**: 카카오 오픈채팅방 개설 승인 + 학원 공지 채널로 링크 안내

- 강사 **응답 가능 시간대를 명시**하고 그 외 시간은 답하지 않습니다 (기대 관리).
- 질문은 공개로 답해 같은 질문 반복을 줄입니다.

## 요약 체크리스트

**개강 3주 전까지**

- [ ] OpenAI Platform 계정 개설 + 결제수단 등록
- [ ] 학원 고정 IP 확인 (`ifconfig.me`, 가능하면 다른 날 2회)
- [ ] 예상 비용 승인 (12주 약 13만~33만 원, 상한 설정으로 초과 불가)

**개강 2주 전까지**

- [ ] 학원 노트북에서 접속 테스트 (강사가 주소 제공, 5분 소요)

- [ ] 작품 공개 범위·수료 기준 결정
- [ ] 학교 과제 활용 방침 결정

**개강 1주 전까지**

- [ ] 학생 명단 전달 (이름·학교급·반)
- [ ] 반별 확정 인원 통보
- [ ] 오픈채팅방 개설 + 학부모 안내문 발송
